# Peeling the Matryoshka · 消化（L1）

> 只到卡 + 一页判断；没有深读正文。事实回 [card.md](./card.md)。

## 为什么只到 L1

它研究的是**检索嵌入里是否编码了分类结构**，不在 harness 回路上；对「本体在哪个时刻被执行」只提供一条旁证。精读的边际收益低于把时间花在 01–06 的承重论文上。

## 一句话判断

MRL 嵌入的**前缀维度**与金标分类法的粗→细粒度对齐；一个 98K 参数的探针能在冻结嵌入上解出分类 DAG。**这说明嵌入里有结构，不说明结构能被 agent 用。**

## 工程思路（如果有用）

- 需要从嵌入快速抽 taxonomy 时，可以试 prefix + order-embedding 探针；成本低。
- 但先确认目标本体不比源域更深；零样本迁移只在这个条件下验证。
- 不要把它当「本体已经内化」的证据；它测的是嵌入几何，不是 agent 行为。

## 质量与边界

- 三个 MRL 架构、Graph F1 0.885/0.931；有对照（打乱/逆序维度）。
- 明确未测下游效用；只在特定嵌入族上成立。
- 与 harness 无关；不能支持「本体提升 agent 表现」。

## 洞察

1. **粗→细粒度在前缀维度里是可读的。** 这对「便宜地抽结构」有启发，但不等于语义正确。`已核`
2. **结构可解码 ≠ 结构可执行。** 对 03/05 来说，这只是「原料可能存在」，不是「能被判定器消费」。`推测`
