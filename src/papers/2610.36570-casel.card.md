# CASEL

## 做了什么

面向工具调用 agent 的**运行时分配层**：不是简单剪掉高风险动作，而是对每个待执行调用，在「直接执行 / 验证 / 沙箱 / 澄清 / 审批 / 弃权」之间选一个模式。

选择依据是五个信号：校准后的失败概率、状态相关的后果、可逆性、歧义、证据新鲜度；目标是最小化每种模式的代价。作者把直接执行形式化为 selective prediction，并测试有限样本阈值与轨迹级风险账本的有效性。

## 结果

控制模拟（20 seeds，每个 120,000 test actions，所有方法同一干预菜单与算力）：

- 有害副作用轨迹：不确定性排序闸门 **14.75% → 7.02%**；平均归一化伤害 **0.184 → 0.123**。
- 按「失败概率 × 后果」排序的闸门：伤害 5.82%、0.120，但**多送 45% 的动作去人工审批**。
- **移除可逆性感知路由**：伤害回升到 **15.53%**。
- 轨迹级风险预算：同等成本下伤害反而升到 **11.82%**。

## 没测什么

**作者自述**：干预有效性是**假设的，不是测量的**；结果只排名模拟器假设下的分配规则，不建立部署有效性。

**读者补充**：没有真实部署、没有真实伤害数据；「本体」在这里更像策略状态/表示，不是领域本体。它是一个接缝/分配机制，不是本体工程论文。

| C-03 | **正面例证**：用「有害轨迹率 / 归一化伤害」而不是任务奖励来量闸门 |
| P1（价值在约束） | 支持「把判断放在动作前」，但提醒代价是审批量 |
| [action-gate](../../topics/01-constraint/action-gate/README.md) | 核心文献：多模式分配是「剪枝」的细化 |

**值得记的两点**：

1. 「剪枝」不是唯一解。CASEL 把干预拆成六种模式，其中审批/澄清/沙箱都能降低伤害；只问「剪不剪」会漏掉成本更低的组合。
2. 「轨迹级风险预算」是一个**负结果**：在同等成本下反而更差。这提醒「预算」类机制不能想当然。
