# Evontree · 消化（L1）

> 只到卡 + 一页判断；没有深读正文。事实回 [card.md](./card.md)。

## 为什么只到 L1

训练侧的自演化：用本体规则检出自检不一致，修正后重训模型。它不改变推理时的 harness，也不提供可执行的约束；对「本体在回路里以什么形式被执行」只有间接关系。

## 一句话判断

用少量本体规则驱动「自检 → 修正 → 重训」的迭代，在专业域提升模型表现；前提是模型预训练已内化大量隐性本体知识，且需要人工选定根概念（15 个）。

## 工程思路（如果有用）

- 如果目标是**训练侧**注入领域一致性，可以把本体规则当弱标签/过滤器，而不是推理时约束。
- 需要人工种子（根概念）；规则覆盖决定能检出的错误类型。
- 不适合需要审计/可解释的推理时闸门。

## 质量与边界

- 摘要级无具体数字；训练侧、非推理时。
- 需要人工种子；规则覆盖有限。
- 与 harness 的「执行」关系弱。

## 洞察

1. **本体可以当训练信号，而不是运行时判据。** 这是 05 生产派的一条路线，但不是 01–04 的约束。`推测`
2. **「自演化」仍需要人给种子。** 15 个根概念是冷启动成本；没有它，规则无从挂载。`推测`
