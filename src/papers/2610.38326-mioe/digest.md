# MIOE · 消化

> 事实、数字、页码回 [card.md](./card.md)。这里只写**我们怎么用**、值不值得、哪里会坏。

## 工程思路

**如果要判断「模型是不是真的在用本体」，不要只看正确率：**

1. **定义两个变量：目标本体关系 + class-specific 辅助属性。** 只看目标会高估「懂本体」；要同时看有没有把无关属性带过去。
2. **用因果干预，不用相关性。** 换掉内部特征，看目标答案是否换成 source、辅助属性是否保持 base；这就是 Cause / Iso。
3. **报 Disentangle，不只报 Cause。** 高 Cause、低 Iso 意味着「换对了，但把别的信息也搅了」；不是干净的本体机制。
4. **优先 distributed subspace 方法。** DAS/MDAS 明显优于 SAE/DBM；SAE 的 Iso 很差。
5. **多任务目标改善 Iso，但会降 Cause。** 这是一个显式权衡，不是免费提升。
6. **多层窗口优于单层。** 中层/中后层的连续 2–4 层比单个 residual site 更能同时保住 Cause 与 Iso。
7. **类级分析不能省。** 具体/规则类（airport/country/currency/university）分离较好；宽泛/异质类（body of water/geographical feature/food）较差。
8. **不要把「可干预」当「有模块化本体」。** 干预能改答案，说明因果可达；不能说明内部有一个干净的本体模块。

## 实用意义

它解决的操作问题：

- **「模型答对了本体题，能不能信它真懂？」** → 不一定；正确输出可能来自别的线索，机制上只部分分离。
- **「本体工程 agent 的判断可靠吗？」** → 需要机制级评估，不只是 benchmark 准确率。
- **「为什么某些类总是错？」** → 类级差异；具体类 vs 宽泛类，干预难度不同。
- **「怎么比较解释方法？」** → Cause–Iso 平面；MDAS 在右上角，但不是 GOAL。
- **「多任务训练有没有用？」** → 提升 Iso、降 Cause；看你要哪一边。
- **「单层干预够不够？」** → 不够；多层窗口更好。

**何时用**：研究本体知识是否被内部计算；比较解释方法；诊断类级失败。

**何时别用**：需要部署级保证；跨模型族外推；把干预结果当因果证明；资源不足以做多层扫描。

## 质量评估

- **证据类型**：机制研究（`已核`，一手正文；因果干预）。
- **样本与对照**：2 模型 × 2 任务 × 5 方法；36 层全扫；多层窗口；Entity/Context；类级分析；开源代码。
- **优点**：因果抽象框架清晰；多方法/多层/多类；开源；结论克制（部分分离）。
- **主要威胁**：只 Qwen3；只两个任务；干预位置单一；聚合掩盖类级；无法区分「表示纠缠」与「方法不够强」。
- **`quality: A` 理由**：机制研究设计严谨、覆盖多方法/多层/多类；但模型族与任务范围有限。

## 洞察

1. **「答对」不等于「内部有本体」。** 正确本体预测可以由部分分离的机制产生；不能从行为正确率推断内部模块化。`已核`
2. **因果可达 ≠ 干净分离。** MDAS 最好也只有 0.59 Disentangle；没有方法到 GOAL（1,1）。`已核`
3. **Distributed subspace 方法 > SAE/DBM。** SAE 的 Iso 0.35，DAS/MDAS 0.58–0.69；稀疏特征不等于因果变量。`已核`
4. **多任务是 Iso/Cause 权衡。** Iso +0.081、Cause −0.052；Disentangle 提升，但不是免费。`已核`
5. **多层窗口 > 单层。** 四层 DAS 512×4 达 0.667（+0.102）；中层/中后层是关键区间。`已核`
6. **类级差异巨大。** 具体/规则类分离好，宽泛/异质类差；聚合分数会掩盖。`已核`
7. **「部分分离」有两种解释：表示本身纠缠，或方法不够强。** 本文不能区分；这是后续研究的关键。`已核`
8. **机制评估是行为评估的补充，不是替代。** 行为 benchmark 告诉你「对不对」，MIOE 告诉你「是不是真的在用本体」。`推测`（方法论判断）

## 成本与使能条件

| 成本 | 一次性 / 每次 | 说明 |
|---|---|---|
| 数据集构建 | 一次性 | 54/39 classes；subjects/attributes/prompts；人工/半自动 |
| 干预训练 | 每方法/每层 | DAS/MDAS 需要训练子空间；36 层扫描成本高 |
| 多层扫描 | 每窗口 | 2/4 层组合；GPU |
| 类级分析 | 每类 | 样本少时方差大 |
| 复现 | 代码/模型 | Qwen3 可本地跑；跨模型需重做 |

**使能条件**：可访问模型内部激活；能训练干预；有 ground-truth 类/属性；GPU。

**2022 年做会卡在哪**：因果抽象/DAS 工具链不成熟；Qwen3 级模型未出现；本体 benchmark 不成熟。

**反向条件**：闭源模型无内部访问；需要部署级结论；跨模型族外推；资源不足。

## 不可迁移

- 只 Qwen3-4B/8B；跨模型族未测。
- 只 entity typing / subsumption；更丰富本体约束未测。
- 单干预位置（subject-token residual stream）。
- 聚合分数掩盖类级差异；类级结论是描述性的。
- 不能区分「表示纠缠」与「方法不够强」。
- 无部署/下游任务评估。

## 开放问题

- 跨模型族（Llama/GPT）是否同样部分分离？
- 更丰富的本体约束（disjointness/domain-range）能否用同样方法测？
- 干预位置（subject token 之外）是否改变结论？
- 「部分分离」是表示问题还是方法问题？需要更强干预/方法对照。
- 类级差异能否预测下游本体工程任务的表现？
- 能否用机制指标筛选「可信的本体判断」？
