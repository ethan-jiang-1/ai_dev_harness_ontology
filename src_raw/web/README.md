# src_raw/web：博客 / 网页 / 工程材料

这里放 `source_type` 为 `blog` / `engineering` / `standard` / `talk` / `survey` 的原样材料；论文 PDF 在 [papers](../papers/)。

## 规则

1. **原样存档。** 不摘编、不改写；网页转 markdown 时保留标题、作者、日期与链接。
2. **命名。** `{来源}/{日期}-{slug}.md` 或 `{来源}/{slug}.md`；同一来源放同一子目录。
3. **登记。** 在 [src_notes/cards/](../../src_notes/cards/) 建卡，并在 [src_raw/README](../README.md) 的目录表加一行。
4. **一手/二手。** 博客可能是作者的一手观察，也可能是转述；卡片写清 `source_type` 与 `provenance`。
5. **证据天花板。** 见 [source-types](../../meta/source-types.md)：博客的 `已核` 只指「作者报告了 X」，一般规律默认 `推测`。
