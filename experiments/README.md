# experiments：验证

流水线的旁路。这里只放**实验设计**，实现产物在仓库外，靠实验编号回链（见 [ADR 0001](../adr/0001-research-repo-over-code.md)）。

## 为什么需要

目前全仓库最强的结论等级是「已核原文摘要」——**没有一个结论是独立复现的**。这意味着所有判断都继承了他人的实验条件，而我们无法确认这些条件是否是我们的条件。

## 三个待做实验

按「能改变哪条假设」排序，不按难度排序。

### EXP-001 · 结构化工件到底有没有用（RQ1 / RQ5）

**要回答**：在**同一个 harness** 下，加与不加结构化工件，差异在哪里。

**设计要点**：
- 固定 harness 与模型，只变「工件有无」与「工件形式」。
- 度量分两套：任务准确率 + **过程指标**（token 总量、检索轮次、重复查询率）。
- 保留上下文预算作为协变量——否则无法区分「工件有用」与「工件省了预算」。

**预期**：准确率无显著差异，过程指标显著改善。若准确率也改善，E-01 需限定范围。
**会推翻什么**：若准确率显著改善 → E-01 必须限定范围；若过程指标也无改善 → 编译派的预算论证失效。
**对应**：[E-01、E-08](../topics/conclusions.md)

### EXP-002 · 判定器的漏检/误报曲线（RQ4）

**要回答**：本体判定器的价值，能否用一条曲线刻画，而不是一个准确率。

**设计要点**：
- 三源本体（人工/生成/挖掘）各建一个判定器，同一批产出上比较。
- 必须同时报告**漏检**与**误报**；只要一个数就没法做取舍。
- 要测「误报导致的修改」——被错误标记后 agent 去改，改坏了多少。这是误报的真实代价。

**预期**：不存在单一向优来源（P3 成立）；误报的破坏力高于漏检。
**会推翻什么**：若某来源在 FP/FN 上同时占优 → P3 被推翻；若误报修复破坏不显著 → 「误报比漏检更贵」降级为推测。
**对应**：[E-02](../topics/conclusions.md)

### EXP-003 · 接缝位置对照（RQ2 / RQ3）

**要回答**：同一份本体放在不同时刻（上下文 / 判定 / 授权），行为差异有多大。

**设计要点**：
- 同一本体的三种投放位置，其余条件相同。
- 度量「不可逆错误的拦截率」而非准确率——按 C-03，用错尺子会得出错误结论。
- 加一组重复运行，测收敛性（RQ3）。

**预期**：拦截率随位置后移单调上升；覆盖率单调下降。
**会推翻什么**：若拦截率不随位置后移上升 → 强度/覆盖反向被削弱；若覆盖率不降 → 该假设被推翻。
**对应**：[E-04、C-03](../topics/conclusions.md)

## 纪律

- 实验失败照样登记，写清失败原因——**失败原因本身就是结论**。
- 每个实验必须预先写明「哪种结果会推翻哪条假设」。没写就别做。
- 实现产物在仓库外，编号与本文档一致；产物丢失时，对应结论降级。
