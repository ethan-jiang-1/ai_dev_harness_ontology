# 术语与内码速查（01）

> 第一次读 01 先看这一页。这里只解释「读 01 会用到的词与码」；完整术语见仓库根 [GLOSSARY](../../../GLOSSARY.md)。

## 1. 两套码，不再撞车

| 码 | 是什么 | 例子 | 不是 |
|---|---|---|---|
| **X1–X9** | 01 的 **9 条期待**（要量什么） | X1「K1 相对 K0 ≥+10pp」 | 不是证据编号 |
| **E-01–E-20** | 仓库的 **跨派结论**（已经形成的判断） | E-12「K1 +54.6pp」 | 不是期待 |

> **X 是期待，E 是证据。** 2026-11-11 起期待改用 `X` 前缀，不再与 `E-xx` 共用字母。01 的 basis 是 E-01–E-20；仓库现在共 27 条 E，另 7 条（E-21–E-27）不在 01 的主路径里。
>
> 数据表文件名仍用 `e3`–`e8`（历史命名），与 X3–X8 一一对应；**文件名不是证据编号**。

## 2. 判定

| 词 | 含义 | 注意 |
|---|---|---|
| **A 可先落地** | 有实现/公式/已测操作 + 边界能写成验收 + 可回退 | 不是「已证」 |
| **B 可试点** | 有一手证据，但边界不能完全写进验收 | 先量 1–3 个数 |
| **C 只能设计** | 有机制/设计，但只有模拟/无实现 | 不是「不值得研究」 |
| **D 反向** | 已测条件下会错/负收益 | 不是「永远不能用」 |
| **非本体（参照）** | 机器没在「执行本体」（例：CASEL 的审批分配） | 不进 A/B/C/D |
| **undetermined** | 只有方向，没有机制/设计/证据 | 不是 C；不伪装成「只能设计」 |
| **A+** | 不存在 | 本仓库无独立复现，最高 `已核` |

## 3. 证据等级与状态

| 词 | 含义 |
|---|---|
| **已核** | 一手原文/代码核对过 |
| **已核（代码）** | 读代码核对过，不是效应量 |
| **推测** | 从一手材料推的，或工程估算 |
| **存疑 / contested** | 主结论可站，某个读法被削弱 |
| **not measured** | 原文没测（例：E-01 的 ontology） |
| **unknown** | 还没有一手证据；不是「无效」 |
| **gap** | 缺数据/缺来源，不进验收 |

## 4. 知识层（K）与指标

| 码 | 含义 | 坑 |
|---|---|---|
| **K0** | 地址级标签：tag 名、点位、原始字段 | 只有名字，没有单位/语义 |
| **K1** | 名字 + 单位 + 别名 + 槽位对齐 | 先 K1，再投影/编译 |
| **K2** | 投影：把领域知识写成固定分节文本 | 不是「本体越全越好」 |
| **p_h** | 命中率：回答所需证据在上下文里的比例 | 不是「检索到没有」 |
| **p_min** | 编译盈亏平衡：`2% + c/(0.929Q)` | 自己的 `c`/`Q` 没量就不能套 |
| **FA** | false alarm：checker 把对的判错 | 与 catch 分开报 |
| **CMR** | 跨期匹配率：同一实体跨会话能否对上 | 与 `Acc@complete` 不是一回事 |
| **pp** | 百分点（percentage point） | +54.6pp ≠ +54.6% |

## 5. 执行形态

| 词 | 机器拿本体做了什么 |
|---|---|
| **context** | 把本体/知识放进上下文，不改动作 |
| **compiled** | 编译成约束/查询/策略，再执行 |
| **engine** | 引擎执行（查询重写、SHACL 校验等） |
| **label** | 给数据打标，不直接执行 |
| **none** | 没有落在机器执行上 |

> 定义与五种形态的选法见 [02 §2.4](../../02-engineering-playbook/sections/map.md#24-选形态五种别把-context-当低配-engine)。**不要把 `context` 当 `engine` 的低配。**
