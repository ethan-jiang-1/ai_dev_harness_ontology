# 手册规划建议（2026-11-09）

> 这是给“回头规划手册”的输入，不是正文，也不是大纲替代。**不要直接据此开写**；先定受众、篇幅与章节顺序。

## 1. 建议的写作顺序

不是按章号写，按“证据最硬、最能暴露 topics 缺口”的顺序：

1. **第三章（约束强度谱）**——全书重心，E-01/E-04/E-12/E-13/E-15/E-16/E-20 都在；写它最容易发现“强端证据不足”。
2. **第一章（差距不在模型）**——E-01、C-03；开头定调。
3. **第六章（选对尺子）**——C-03、E-18；把“为什么准确率不够”讲透。
4. **第四章（六个接缝）**——E-02/E-03/E-04/E-05/E-07/E-08；反例多，注意别写成成功案例集。
5. **第二章（七部件）/ 第五章（来源）/ 第七章（领域）**——按素材成熟度补。

## 3. 结构建议

- **第三章的骨架**：先拆“强度 ≠ 好坏”，再走 `context → memory → evidence → checker → action → commit` 六个位置；每个位置写“能拦什么/拦不住什么/代价/证据等级”；最后给选择规则（按错误是否可逆、代价、审批量），不要给单一评分。
- **第三章的核心图**：强度–覆盖反向图，用派谱（03 知识 → 04 状态 → 02 判定 → 01 约束）作 spine，六个位置作为派谱下的展开刻度；不新建第四张分类谱，分类仍以派轴/时刻轴为准。图上必须标“组织假设（非 E）”；E-01/E-04 只作为边界证据，不作为图的证明。
- **第四章的反例**：优先用论文自述的失败/回退（E-04 的 retail/强模型回退、E-01 的 PageIndex 退化、E-07 的 SLB），不要编客户案例。
- **第六章的度量表**：按“机制类型 → 失效形态 → 主指标 → 过程指标 → 非对称代价”做一张表；表里只放 topics 已有的判断，缺的留空并标注 gap。
- **E-20 的位置**：放第三章的“执行形态”小节，或第六章的“尺子”小节；它是代码级分类，不是效应量，不能拿来证明“形态改变行为”。

## 4. 写作纪律

- 只引 `E-xx`，不引 `L-xx`；每条要点能反查到 `topics/`。
- 已核/推测/存疑必须同页标；不要把 `推测` 写成既成事实。
- 不新增判断；写不动的地方回 `topics/` 或 `frontier`，不要用“通用经验”补。
- **不要重新引入实验/D0/客户资产**；手册是抽取，不是验证。
- 不要为了“完整”给每章硬凑案例；宁可留一个显式 gap。
