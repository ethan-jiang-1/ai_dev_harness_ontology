# 05 · production-landscape — SCOPE（定位契约）

> **改/建本交付物前必读。** 本页是 05 定位的唯一权威；五份的总索引与共用规矩见 [meta/deliverable-scope](../../meta/deliverables/scope.md)。
> 本份承接 04 原来想答、却答偏了的问题：**业界真实落地现状 + 靠谱与否的证据**。

## 初心（为什么有这份）
回答用户真正的问题——本体在业界真实落地到什么程度？有没有可靠证据说它靠谱 / 不靠谱？

## 定性
**现状**（描述性 · **实证**）。必须用真实生产 / 业界证据，不是合成教程。

## 回答的问题（一句话）
现在业界谁在上本体、上到什么规模、成本收益如何、靠谱与否有无可靠证据？

## 读者拿到什么
真实生产 / 业界落地的实证图景：重型 → 轻型谱系、成本锚点与缺口、成败案例、证据分级。

## in-scope（该干的）
真实生产部署 / 业界采用证据、成本收益实测、采用谱系（Palantir 式重型 → LLM 辅助薄语义轻型）、靠谱与否的证据、成本拐点。

## out-of-scope（不该干的，去哪）
- 合成怎么建 → 04；配方 → 02；机制理论 → 03；能力判定 → 01。

## 红线（绝不能）
- **必须用真实生产 / 业界证据**（admitted，含 CHARTER §4.4 公司生产报告窄例外）。
- **禁止用合成示例 / 理想化做法冒充现状**（04 的教训）。
- 时效 / 活跃 / 影响按 CHARTER §4：≥2026-06、活跃有效、多主体支撑；孤证 / 过期 / 厂商自证不进。

## 发挥空间（scope 内你可以）
综合 admitted 生产证据画现状图景、分级、指出证据缺口。**不能编现状、不能拿 04 的 fixture 当证据。**

## 答不了怎么办（当前状态）
**证据基座已补，但仍不完整**（2026-11-12）：新增 5 条 admitted/probation 生产证据（中泰证券 QCon/CCSA、Snowflake 内部语义层、Sigma 2,883 模型语义层、Netflix 可观测性本体）+ 1 张 admitted 格式卡（Google OKF）+ 2 条 OKF 采用线索（中泰 admitted、京东海博 signal），足以写「谁在跑、什么形态、规模多大、失败长什么样、Wiki/OKF 能不能当一条路线」；仍缺**同时披露规模 + 成本 + 失败 + 独立印证**的 A 类全量案例。答不了的成本/ROI 与「哪家更靠谱」标 gap，不编：成本只能写到「有价目/合同/运行费锚点，无全生命周期账本」；中国大厂的 2026-06 后外部采用证据也标 gap。
