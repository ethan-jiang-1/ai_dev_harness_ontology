# 核心计划：把“证据不够”的地方改成“敢说不知道”

> **只读这一页就够。** 下面不要求你先看 CHARTER、ADR 或别的文档；需要知道的背景、规则、进度、验收，都在这里。

## 0. 一句话

**这次不是给仓库再加一层文档，而是把交付物里“看起来有证据、其实来源已经不合格”的判断，逐条改成三种诚实状态之一：还能用 / 只能试点 / 暂时不知道。**

目标不是让文档“看起来完整”，而是让读者**不会因为旧数字拍错板**。

## 1. 为什么要做这件事

仓库在 2026-11-11 做了一次“素材准入”重置：

- 以前收材料偏宽：单机构、无采用、过期、公司自证的材料也进来了。
- 新规则要求：**只有通过五道门（时效、活跃、影响、来源、可核验）的材料，才能支撑判断。**
- 重置结果：论文 28→10，材料卡 15→11，**9 条跨主题结论（E）撤回、27 条局部判断（L）撤回、15 个硬对象撤回**。

问题在于：**源删了，但交付物里的数字和 A/B/C 评级还留着。** 读者看到的是一张“有证据”的表，实际上有些行的证据已经不存在了。

所以这次收口要做的，不是“再研究一遍”，而是：**把失去证据的判断降级、撤回或标成“暂时不知道”，并说清为什么。**

## 2. 核心思想（四句话）

1. **判断跟着源走。** 源被撤回，判断不能靠“以前引用过”继续活着。
2. **“不知道”是合法状态。** 没有合格证据时，标“暂时不知道”，不要硬塞进“可试点”或“只能设计”。
3. **术语不能借权威。** 一篇论文的实验条件，不能写成“行业层级”；本仓库自造的词，必须标“本仓库用法”。
4. **先收口，再美化。** 不重写结构、不新造框架；先让证据和定义站得住，再谈文笔和评分。
5. **先清后补。** 先把旧的、过期的、没有说服力的信息扫描干净，确认干净了，再补新信息；不要在脏底上叠新层。
6. **术语必须有出处。** 专业术语只能来自 N 层标准；I 层论文只能给证据/条件编号，不能定义术语。K0–K4 不是术语，主路径不用。

## 4. 不做什么

- **不重写六派/交付结构。** 结构不是这次的问题。
- **不新增 E/L。** 这次只做撤回、降级、改定义、补状态。
- **不把标准卡当效果证据。** 标准只能定义词和合格性，不能证明“用了本体 agent 更准”。
- **不把“有人在说”写成“已经证明”。** 线索只进候选队列，不进交付物。
- **不擅自 commit。** checkpoint 由用户点头后执行。

## 6. 工作分解（按顺序）

### 第 1 步：01 重判（已完成）

- **做什么**：把依赖已撤回证据的 4 行移出 A/B/C，单独列“暂时不知道”；重算计数；改首屏、地图、阈值页、决策记录、验收、边界。
- **产出**：01 的 A/B/C/gap 表与计数。
- **验收**：01 里没有任何一行把撤回证据标成“已核”；计数在 README、地图、阈值页三处一致。

### 第 2 步：02 重判（已完成顶层）

- **结果**：A=3 / B=4 / C=1 / gap=4（不含 R0）。

### 第 3 步：03/04 标注（核心段完成）

- **验收**：交付物里不再有“撤回证据仍标已核”的结论句。
- **剩余**：少量长尾旧数字还带“历史”标注，未逐句删。

### 第 4 步：术语 v0（已完成）

- **结果**：10 词中 2 个有标准锚，7 个本仓库自造，1 个从标准收窄；K0–K4 标“论文条件”。

### 第 5 步：全量扫描旧噪声（下一步，先做这个）

**原则**：这一步只清，不补。**没有通过第 6 步的“干净门”，不许开始第 7 步的主干接线。**

扫描范围：01/02/03/04 的 README、sections、capabilities/recipes/positions、appendices、data。

要抓的五类东西：

| 类型 | 例子 | 处理 |
|---|---|---|
| **撤回证据当结论** | 撤回的 E 仍标 `已核` / `支持` / `可试点` | 改成 gap/撤回，或删 |
| **旧效应量** | 50.5/68.1、18 格/8 改善、catch/FA 旧值、9.7k tokens | 删具体值，只留“待新源”；历史页可保留但必须标历史 |
| **旧链接** | 指向已删源、非 tombstone | 改到审计锚点或删 |
| **借权威** | 把论文条件/社区模型写成“行业标准/成熟度” | 改 local/论文条件 |
| **论文条件当术语** | K0–K4 进标题/主列/判定名 | 改成 plain name；K 只留出处/回查 |
| **旧计数** | 14 行 A/B/C、B=7、C=3 等与现状不符 | 以 map/canonical 为准重算 |

**产出**：一张扫描表（文件 / 行 / 类型 / 动作 / 状态），放在 `deliverables/_plans/2026-11-11-scan-report.md`（新建）。

**验收**：扫描表里每一行都有“已改/已删/保留为历史”三选一；不允许“先留着”。

### 第 6 步：干净门（第 5 步之后，未过不许补）

**做什么**：用固定检查确认“旧噪声已经清掉”，而不是凭感觉。

- 搜撤回 E 是否还被标 `已核`/`支持`：结果必须是 0（除了“撤回/历史”语境）。
- 搜旧效应量：结果必须只剩“历史/撤回”标注。
- 搜“行业标准/成熟度”：只允许否定句或 local 说明。
- 搜 K0–K4：主路径的标题/主列/判定名里不能有 K；只允许“论文条件/出处/回查”语境。
- 跑 `check_repo`：0 坏链 / 0 坏锚 / 0 未定义 ID。
- 抽 10 个定义句：每个都有 `N:` 或 `local`（这一步可以和第 7 步一起收，但“旧噪声清零”必须先过）。

**产出**：在扫描表顶部写一行“干净门：通过/未通过 + 日期 + 命令”。

**不过怎么办**：回第 5 步，不进入第 7 步。

### 第 7 步：补入规范主干（干净门通过后）

**为什么先做 01**：它是决策页，定义最集中；02/03/04 的术语也回指 01。

#### 7.1 先列定义清单

把 01/02/03/04 的**定义句**摘出来，每句标四种状态：

- `N`：有规范锚（标准能定义）；
- `I`：只有资料性证据（论文/代码/数据）；
- `local`：本仓库自造，必须首现解释；
- `gap`：原锚撤回，暂时不知道。

> 不是给每句话找标准；**只给“定义词/合格性”的句子找 N**。效应句归 I。

- 没有“标准证明效果”的句子；标准卡只出现在定义/合格性处。

- **不为接线重写章节**；只改定义段、首句、来源行和边界句。

## 7. 怎么判断没走偏（五条红线）

1. **源没合格，判断不能留。** 唯一支撑被撤回，就撤回或标 gap。
2. **“暂时不知道”不是失败。** 把 gap 伪装成 B/C 才是失败。
3. **标准卡不能撑效果。** 标准只能定义词和合格性。
4. **自造词必须标。** 不能把“本仓库用法”写成“行业共识”。
5. **每批跑自检。** `check_repo` 失败就不往下走。
6. **论文条件编号不是术语。** K0–K4 只能出现在出处/回查；不能进标题、主列、判定名，也不能写成“行业层级”。
