## 2. 七条证据缺口：关闭判据 + 检索面

每条先查[黑名单](../../meta/rules/excluded-sources.md)，再按 [CHARTER §4](../../CHARTER.md#4-素材准入material-gate) 过门。

### G2 中国大厂 2026-06 后外部采用（最高优先，可能改变 E-30）

- **关闭判据**：具名客户 + 日期 + （规模 或 成本）+ 可追一手；客户侧或第三方署名，不是平台方产品页。
- **已试**：官网、云文档、开发者社区、会议（QCon/CCKS/AICon/云栖/HC）、招聘、采购平台、案例库、arXiv → 0 条。
- **未试/新面**：
  1. 云厂商**客户案例页**逐条翻（alibabacloud.com/customers、huaweicloud.com/cases、tencentcloud.com/customer-stories、jdcloud 案例、antgroup 技术博客）；
  2. **按中标方**检索中国政府采购/招标聚合站（"阿里云 中标 知识图谱/本体/语义"、"腾讯云 中标 知识中台"、"华为云 中标 数据治理 本体"）；
  3. **行业奖项/案例集**（金融科技创新奖、信通院案例集、CCF 科技进步奖、地方国资委数字化转型案例）；
  4. **会议 industry track** 2026-06 后客户联署（QCon/ArchSummit/GIAC/DTCC/中国数据库技术大会）。
- **判级**：平台方一侧 = C；采购公告 = 采购记录（可到 B-，只证买不证成）；客户署名复盘 = A 候选。

### G3 TCO / 人月（最高优先，A1 天花板的直接来源）

- **关闭判据**：一份材料同时给"团队规模（人）× 月数"或"人月单价 × 人月"；或同一买方的建设合同 + 维护/续费合同配对。
- **已试**：工程博客、会议、USASpending、UK Contracts Finder、TED、中国政府采购网、招标聚合站、上市公司募投、招聘 JD → 只有江南农商 3 人组（signal）。
- **未试/新面**：
  1. **审计机关报告**（NAO 英国、GAO 美国、ANAO 澳洲、EU ECA）：数据/语义/知识平台项目的成本、工期、结局，常带预算与人力；这类是 I1 级来源；
  2. **TED / Find a Tender 附件**：带 person-day / 工作量表的标书与合同（搜 semantic interoperability / reference data / ontology，看 award notice 附件）；
  3. **arXiv 工业论文**：2026-06 后带"N 人 × M 月"建本体/KG 的产业作者论文；
  4. **中国招标文件正文**的工作量清单（部分在付费墙后，换聚合站/中标公示附件）；
  5. **公开的 SOW / 项目复盘 PPT**（会议资料包）。
- **判级**：审计报告 = I1；标书附件 = 采购记录；厂商软文/构造案例 = 排除（见 90.3 已剔除的 Data Praxis、玄同科技）。

### G5 项目级 postmortem（可能改变 E-29 的强度）

- **关闭判据**：具名组织 + 项目阶段 + 结局（取消/回退/降级）+ 规模或成本。
- **已试**：英文工程博客、HN、KGC/SEMANTiCS 议程、TED、UK Contracts Finder、中国政府采购网、arXiv → 未找到第一方复盘。
- **未试/新面**：
  1. **审计机关的"中止/超支/未达预期"报告**（同上 NAO/GAO/ANAO，这一面同时服务 G3）；
  2. 政府/国企**数据中台、知识中台关停或降级**的公开报道；
  3. 会议里的 "lessons learned / what we killed" 类型 talk；
  4. 供应商替换公告（窗口内的技术性替换，非 Westpac 那种非技术退出）。
- **判级**：审计报告 = I1；媒体报道 = 媒体转述，只到 signal。

### G6 同数据集对照（本体 vs 无本体）

- **关闭判据**：同一数据集/任务上，有/无本体（或厚/薄）的对照，且有分母与指标。
- **已试**：论文/工业报告 → 窗口内未找到生产级对照。
- **未试/新面**：arXiv 2026-06 后工业 A/B；benchmark 官方榜单里的"with ontology / without"分组；会议 poster。
- **预期**：大概率仍阴性；阴性就写进 90.3，不改结论。

### G4 失败率 / 成功率（有可核分母）

- **关闭判据**：样本框 + 分母 + 失败定义 + 年份，四件齐；否则仍是 signal。
- **已试**：Atlan/Improvado（不可核，已撤）、HN、咨询报告 → 无。
- **未试/新面**：信通院/CCSA 的问卷型报告（看是否给 N）、学术 survey（有 sampling frame）、行业协会年报。
- **判级**：给分母的问卷 = signal 上限；不给分母 = 不引。

### G1 四项齐全的 A 类案例

- **不单独检索**：它是 G2/G3/G5 任一命中后的自然结果。命中即回填。

### G7 Snowflake / Sigma probation 第二信号

- **关闭判据**：第三方引用其规模数、外部组织采用、或独立参会者复盘。
- **已试**：HN 0 条、daily.dev 仅自动转贴、dbt/Sigma 同机构不算（2026-11-12）。
- **未试/新面**：其他厂商/分析博客引用该文（引文网络）、dbt Summit 2026 的第三方 recap、Snowflake 社区论坛讨论。

## 4. 执行顺序

1. **证据研究**（G2 → G3/G5 → G7 → G4/G6），每条一搜一记，命中即建卡；
2. **上游回写**：mechanism → findings → claims →（必要时）conclusions；
3. **05 回写**：08 缺口表 → 05 经济 → 04 中国 → 06 台账 → 90 来源/90.3；
4. **文档层**：冷读 → 按回执修 → 有余力再压 C2；
5. **收口**：check_repo → state/state-log → 本页状态改"已执行" → _plans/README 更新。

## 5. 停 / 不做什么

- **不做**：不重画 SVG；不写代码；不为"完整"建空节；不用厂商材料填缺口；不把"没公开"写成"没做"；不把"美国公开多"写成"美国更成熟"。
- **停**：同一检索面连续两轮无增量 → 记阴性收手；
- **停**：命中材料过不了门且无法补信号 → 记 frontier 候选，不回填；
- **停**：另一线程正在改同一文件 → 等其静止（mtime 静默 ≥3 分钟）再动，冲突时保留其改动。

- 检索：每条缺口 ≤6 轮外部检索；无增量即收。
- 写：单文件单次编辑，不整文件覆写。
