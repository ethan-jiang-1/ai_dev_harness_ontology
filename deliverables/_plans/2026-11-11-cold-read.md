## 4. 结果 C：N/local 标记是帮助还是噪音

代理判定：**帮助，但剂量与位置不对**。只有两处改变了读者决定：

- 「本体 = `N: ISO/IEC 21838-1`（本仓库义更宽，判 `broader`）」——挡住「文中本体 = ISO 本体」；
- 「约束/校验 = `N: W3C SHACL`，只到 RDF 图约束，**不到动作授权**」——提前否决「有 SHACL 就有授权」。

其余 `local` 标记是出处元数据，不改变决定。代理建议：正文留这两处警告，其余下沉术语表。

**处置**：01 README 的「词源速查」已从 8 行压到 2 行（只留这两处 + 术语表链接）；四个术语页的 §0 表保留全部词源（那里是查询处，不是通读处）。**没有全面撤掉正文标记**：核心计划的验收要求「定义句后有 N 或 local」，且位置卡的机制定义需要就地标注。
