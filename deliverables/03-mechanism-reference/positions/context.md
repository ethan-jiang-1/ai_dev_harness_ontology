# context：模型看到什么

> **一句话**：本体在这一格只被「读」，不被「执行」。它能改变模型知道什么，不能改变模型必须做什么；把它当约束用，是这一格最常见的误用。

> **为什么不是相邻位置**：不是 memory（不跨轮）、不是 evidence（不改输出字段）；它只改模型看到什么。

## 1. 机制

本体在这里以两种形态进入上下文：

| 形态 | 机器做什么 | 模型做什么 | 典型产物 |
|---|---|---|---|
| 投影 projection | 把领域知识写成固定分节的文本/记录 | 阅读、检索、引用 | 约 45k 字符的本体塔投影（E-12） |
| 编译 compilation | 把证据预整理成 claim + 逐字 span 的工件 | 用工件替代整段阅读 | claim 索引、导航树（E-08/E-14） |

两种形态都没有外部求值：没有「违反就拒绝」的代码路径。模型可以读，也可以不读；可以照做，也可以忽略。**「投影里写了规则」不等于「规则被执行」**——这一条没有 prompt-vs-code 对照，标 `推测`，但 live run 的安全层独立于 agent 是 `已核`（E-12）。

## 2. 触发、输入、输出

| 项 | 内容 |
|---|---|
| 触发 | 每次请求组装上下文时；编译在索引时预生成 |
| 输入 | 本体/塔、描述记录、源文档；编译另有 chunk、span、版本、ACL |
| 输出 | prompt/context 文本或结构化记录；**没有 verdict 字段** |
| 下一步 | 模型自行使用；是否遵守由模型决定，不由这一格保证 |

## 3. 能改变什么

- **知识即答案时，改变答案。** K0（地址级标签）→ K1（tag 名 + 单位）避坑率 +54.6pp；K1 → K2（投影文本）+19.8pp（0.605→0.802，OR 5.45，p=6.0×10⁻⁷）。`已核`（E-12；单工厂、9 任务、答案基本写在文本里）
- **投影形态有排序，但不是普适规律。** 文本 0.777（pooled element score）> JSON 0.717 > 查询工具 0.638 > 文档检索 0.597；GLM-5.2 的 JSON 0.900 反超文本 0.891，Qwen 的工具 0.407 低于其文档检索 0.538。`已核`（分数）/ `存疑`（排序；事后描述性比较，非受控）
- **编译能省 token，但是条件性的。** 证据充分时 −91%，不充分时 +1.9%，平均 −38%；盈亏平衡 `p_h > 2% + c/(0.929Q)`。`已核`（E-08/E-14；FRAMES、单 compiler/answer model）
- **强检索 harness 会吃掉被测量结构化工件的准确率增益。** 摘要树、PageIndex 大纲、wiki、entity graph 在 FRAMES 上无可检出增益，PageIndex 同规模退化；**原文的 ontology 是 `not measured`，不能读成「本体无增益」**。`已核`（E-01；单基准、无 CI）

## 4. 拦不住什么 / 失效模式

| 失效 | 说明 | 证据/等级 |
|---|---|---|
| 规则被忽略 | 投影写了规则，模型仍可能不执行；没有 prompt-vs-code 对照 | `推测`（E-12 的边界；安全层独立是 `已核`） |
| 投影即答案 | 任务答案基本写在投影里，测到的是「抄得准不准」，不是「理解得对不对」 | `已核`（E-12 的任务限定） |
| 体积/顺序失控 | 45k 字符已接近中型上下文；打乱句序 0.777→0.685 | `已核`（E-12） |
| 投影与本体不同步 | 本体改了、投影没重生成，模型学到旧规则 | `推测`（机制推断） |
| 不可追溯 | 文本陈述不能指回节点；查询工具能，但不是所有模型会用 | `已核`（E-12） |
| 强 harness 下无准确率增益 | 被测量的结构化工件；ontology 未被测 | `已核`（E-01） |

## 5. 使能条件

- 封闭域、操作手册型知识，答案基本写在材料里；
- 投影：有稳定的描述记录与固定分节生成器；能承担 token/维护成本；
- 编译：先量自己的 `p_h`、miss penalty、`c`、`Q`，`p_h ≥ p_min` 才买；
- 需要硬约束时，**另接** action/checker/commit；不要在这一格承诺拒绝逻辑。

## 6. 证据与边界

| 证据 | 等级 | 支持什么 | 不能证明什么 |
|---|---|---|---|
| E-12 | 已核 | 投影文本的分数；K0→K1、K1→K2；顺序敏感 | 跨域排序；深度本体；文本永远最好 |
| E-14 | 已核 | 编译盈亏平衡的条件性 | 无条件省 token；上线收益 |
| E-08 | 已核 | claim–leaf 的 token 条件（−91%/+1.9%/−38%） | 准确率提升 |
| E-01 | 已核 | 强 harness 下被测量结构化工件无准确率增益 | 本体无增益（ontology `not measured`） |

> 这一格的主证据是 **知识供给**，不是 **本体执行**。E-01 尤其容易被读过头：它测的是摘要树/大纲/wiki/实体图，不是 OWL/DL 本体。

## 7. 可证伪条件

- 同一本体、同一任务，在强/弱 harness 下准确率无差异 → 收窄「强 harness 吃掉增益」的边界；
- 同一投影内容，写成 prompt vs 编译成代码约束，行为无差异 → 收窄「投影不等于约束」；
- 投影里写规则后，违反率显著下降且不是模型自述 → 推翻「投影不承担拒绝逻辑」；
- 跨域复现 K1→K2 的 +19.8pp，且答案不在文本里 → 扩大 E-12 的适用范围。
