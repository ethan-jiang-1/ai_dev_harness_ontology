# 覆盖率：从一条线到一张矩阵

> 03 原来的「强度–覆盖率反向」是一条线。线的问题是：没有定义、没有测量、不可证伪。把它换成「失效类别 × 位置」的矩阵。
>
> **这是分类设计（D），不是测量。** 上游在 [topics/06-measure/metrics/coverage.md](../../../topics/06-measure/metrics/coverage.md)；只抽取，不新增格子。

## 1. 覆盖率是什么

**覆盖率 = 某个位置能碰到的失效类别集合。** 不是百分比，不是召回率，不是「能防多少种错」的计数。

| 符号 | 含义 | 判据 |
|---|---|---|
| `●` | 能阻断/改变走向 | 能在坏结果发生前或发生时阻止；有实现或强机制证据 |
| `◐` | 能发现、标注或部分影响 | 能看见/缩小，但不能单独阻止；或只在部分条件下有效 |
| `○` | 碰不到 | 不接触这类坏结果的产生路径 |
| `?D` | 只有设计，无实现 | 机制上应该能碰，但没有实现/没有可核对代码 |

> 格子的默认假设：该位置按它最强的可用策略接线（能阻断的接阻断，能标注的接标注）。这描述**机制能力**，不描述部署现状。

## 2. 七类失效

| ID | 失效类别 | 典型坏结果 |
|---|---|---|
| A | 不可逆动作被执行 | 转账、对外发送、删除唯一副本 |
| B | 语义错误产出 | 关系方向反、类目划错、数值错 |
| C | 无依据产出 | 编造引用、引用与答案无关 |
| D | 状态/身份错配 | false merge、false split、旧值覆盖新值 |
| E | 错误落盘 | 错误合并写回 MDM、错误配置入库 |
| F | 不可复现 | 同一需求两次生成本体不一致 |
| G | 中间产物错误传播 | 错误计划被继续执行、错误摘要被当事实 |

> 七类不是穷尽；新增一类要有独立反例，不为凑表。

## 3. 矩阵

| 失效类别 | context | memory | evidence | checker | action | commit | read-path | determinism |
|---|---|---|---|---|---|---|---|---|
| A 不可逆动作 | ○ | ○ | ○ | ○ | ?D | ◐ | ○ | ○ |
| B 语义错误产出 | ◐ | ◐ | ◐ | ◐ | ○ | ○ | ◐ | ○ |
| C 无依据产出 | ◐ | ○ | ◐ | ◐ | ○ | ◐ | ◐ | ○ |
| D 状态/身份错配 | ○ | ● | ○ | ○ | ◐ | ◐ | ◐ | ◐ |
| E 错误落盘 | ○ | ○ | ○ | ◐ | ◐ | ?D | ○ | ○ |
| F 不可复现 | ○ | ◐ | ○ | ○ | ○ | ○ | ○ | ?D |
| G 中间产物错误 | ◐ | ◐ | ◐ | ◐ | ○ | ○ | ○ | ◐ |

### 3.1 读矩阵四条

1. **位置是专门化的，不是一条强度线的刻度。** 撤回 E-02/E-04 之后，矩阵里只剩 `memory × D` 一个 `●`；`action × A` 从 `●` 降为 `?D`（只有机制设计、无实现证据），`checker × B` 从 `●` 降为 `◐`（只能碰结构/声明错，语义错抓不到）。
2. **强端的窄，是「能阻断的类别少」，不是「能影响的类别少」。** `checker` 有 4 个 `●/◐`，`action` 只有 2 个（A 是 `?D`、D 是 `◐`）；强弱不能按格子总数排。
3. **弱端不是强端的低配。** `context` 对 B/C/G 都是 `◐`，没有 `●`；它的价值是覆盖广、成本低，不是「差一点就能拦」。
4. **C/E/F/G 四类没有 `●`。** 不是只有 G：C（无依据产出）、E（错误落盘）、F（不可复现）也没有任何 `●`；G 只是 `◐` 最密的一类（5 个）。这与附录 §3.5.2 的「中间产物空档」不冲突，但「只有 G」是错的；这里是分类判断，不是测量。

### 3.2 关键格子的判据（为什么是 ●/◐/○）

| 格子 | 符号 | 为什么 | 证据/边界 |
|---|---|---|---|
| action × A 不可逆 | `?D` | 机制上应该能按逆序列 veto；原锚 E-04 已撤回，仓库内也没有实现/可核对代码 | E-04 withdrawn；无实现 |
| checker × B 语义错 | `◐` | 能碰结构/声明/模式错，抓不到「意义变了」；原锚 E-02 已撤回 | E-20（三态/接口）；语义错需 judge |
| memory × D 身份错配 | `●` | registry 对齐实体；false merge 未测 | E-05/E-17；专有数据 |
| context × B/C/G | `◐` | 供给能影响但不能阻断 | E-01/E-12；单工厂 |
| commit × E 错误落盘 | `?D` | 只有设计，无实现 | E-20 否定证据 |
| read-path × C 无依据产出 | `◐` | 删 subject 侧可见性，不是判据 | E-20；object 方向漏 |
| determinism × F 不可复现 | `?D` | 只有设计 | E-17/E-18；跨轮≠跨运行 |
| action × B 语义错 | `○` | 动作闸不验输出语义 | 机制判断；原 E-04 已撤回 |

**读法**：`●` 不是「效果好」，是「有实现/强机制证据，能在坏结果前或发生时阻断」；`◐` 是「能影响但不能单独阻断」；`?D` 是「只有设计」。这张表解释格子，不替代效应量。

## 4. 与「强度–覆盖率反向」的关系

| 读法 | 是否成立 | 说明 |
|---|---|---|
| 越强，能**阻断**的失效类别越少 | **方向性成立、不是单调** | `●` 计数：context 0 / memory 1 / evidence 0 / checker 0 / action 0 / commit 0；撤回 E-02/E-04 后只剩 memory 一个 `●` |
| 越强，能**影响**的失效类别越少 | **不成立** | `checker` 有 4 个 `●/◐`，`action` 只有 2 个；`memory` 也有 4 个 |
| 强度可以排成一条线 | **不成立** | 位置是专门化的；`commit`/`determinism` 的 `?D` 不能当强弱 |

所以 03 保留直线作**摘要**（强端少而硬、弱端多而软），但把矩阵作**操作定义**：要问「这个位置能不能碰到这类失效」，查矩阵，不查直线。**直线不是定律**：`commit`/`memory` 就是反例。

> **组织假设（H）**：强度–覆盖率反向仍然没有被直接测量。矩阵是它的操作化尝试；矩阵本身也是设计（D），不是 E。直线与矩阵都不能证明「强端更好」。
>
> **2026-11-11 更正**：E-02/E-04 撤回后，`action × A` 由 `●` 降为 `?D`、`checker × B` 由 `●` 降为 `◐`——原来的 `●` 是靠已撤回的效应量撑的；机制设计仍在，但没有 admitted 证据，不能写「能阻断」。

## 5. 这张表不能证明什么

1. 不能证明「强端更好」或「弱端更好」；矩阵不标代价、频率、严重性。
2. 不能证明覆盖率可加；七类不是等权，A/E 的一次事故可能大于 B 的一百次。
3. 不能证明跨域成立；换域后某些 `◐` 可能变 `○`。
4. 不能把 `?D` 当 `●`；commit/determinism 只有设计。
5. 不能替代按机制分派的指标；矩阵回答「能不能碰到」，[measurement](03-measurement.md) 回答「碰到后量什么」。

## 6. 什么会改变它

- 一个位置能阻断它标 `○` 的类别 → 改格；
- 一个类别没有任何位置能 `◐` → 新增空档，回到 [gaps](../05-evidence/03-gaps.md)；
- 同一类别在两个域覆盖不同 → 加「域」维，或明确本表只适用于已测域；
- 出现可复算的覆盖率测量 → 矩阵降为分类附录，测量进 metrics 的 G1。
