# 03 横切页：量什么、覆盖什么、形态是什么

> 本目录不按位置切，按「横切问题」切；位置卡回答「这个位置怎么跑」，这里回答「怎么量、能覆盖什么、形态怎么分」。

| 文件 | 回答 | 什么时候读 |
|---|---|---|
| [measurement.md](./measurement.md) | 每个位置该量什么、不能量什么 | 设计验收 |
| [coverage.md](./coverage.md) | 七类失效 × 八位置的矩阵；H/D 标记 | 查强度–覆盖率 |
| [execution-forms.md](./execution-forms.md) | 执行链与四种 `engine` 语义 | 查「有引擎」 |

**读法**：先 `coverage` 看分类，再 `measurement` 看尺子，最后 `execution-forms` 看形态。
