### 1.1 三条说明

- **M1 是承重墙。** 它不成立，六位置表仍可作分类，但 P2「位置/形态改变效果」只能停在「已核但未直接测」。
- **M2 已经从「无定义」推进到「有分类」。** 矩阵把覆盖率拆成七类失效 × 八位置；它仍不是测量，但每一格可被单独反驳。这比一条无单位的直线强，但不等于 M2 成立。
- **M5 不在本仓库做。** 没有实验目录、不请求客户资产；独立复现只能仓库外做并留 `EXP-xxx` 指针。03 不因 M5 未关而阻塞。

## 3. M1/M2 最小协议（未开）

> 只写协议，不跑；跑它需要仓库外实验与标签。**不是新 E。**

### 3.1 M1：同本体跨位置

- **固定**：一份本体 O、一个任务集 T（30 条）、一个模型 M、一个度量。
- **两个位置**：A = O 作 context（注入）；B = O 作 checker（SHACL 校验/拒绝）。
- **重复**：每个位置 5 次；报 task success / harm / false-block 的均值与方差。
- **判据**：位置间差异 > 位置内 run-to-run 方差（E-18 的 54% 噪声是警告，不是阈值）；且方向在 3 个 seed 上一致。
- **不可识别的情况**：两个位置需要不同任务集 → 不能归因给位置；先统一任务，再谈位置。

**外部检索（2026-11-11）**：**没有找到**「同一份本体固定在 context / checker / rewrite 三个位置」的受控对照。最接近的四条：

| 来源 | 它做了什么 | 对 M1 的用法 |
|---|---|---|
| Grammar Prompting（arXiv 2305.19234） | 同一形式文法放 prompt vs 约束解码；2×2 消融；收益主要来自 prompt，约束解码约 3× API 调用 | **最接近的模板**：同一形式规范、两个位置、同一任务 |
| Let Me Speak Freely（arXiv 2408.02442） | 格式限制越严格，推理退化越大 | 约束位不是中性的；M1 要把「格式限制强度」当混淆项 |
| ANCHOR（arXiv 2606.01208） | prompt 内联 schema vs 检索 + SHACL 校验 | 系统级对比，不是同本体消融；只能作设计论证 |
| Lost in the Middle（TACL 2023） | prompt 内部位置（首/中/尾）影响结果 | **M1 必须控制这个混淆项**，否则测到的是位置效应 |

→ **M1 的最小协议要加两个控制**：①同一个本体的呈现位置（首/中/尾）固定或轮换；②格式限制强度（无/松/严）单独一臂。否则「位置差异」会被 Lost in the Middle / Let Me Speak Freely 的效应污染。

**M1 阻塞（2026-11-11）**：[meta/models.md](../../../meta/models.md) 明确 subagent 带工具/仓库上下文，不是干净被试；bash 直连 Yovole 超时。没有 raw chat endpoint，**2×2 跑不了**。协议与混淆项已备；结果标 `未测`，不伪造。

**dry-run（2026-11-11）**：用 3 条样本把 2×2 的表头填了一遍（位置 A/B × run 1–2），确认字段（task success / harm / false-block）可填；没有模型输出，所以没有数值。这一步只验证表结构，不是测量。


### 3.2 M2：强度–覆盖率

- **操作化**：用 [coverage](../across-positions/coverage.md) 的 A–G × 8 位置矩阵，数每列 `●`/`◐`。
- **判据**：如果「越强 → `●` 越少」成立，列计数应随强度单调不增；当前是 0,1,0,1,1,0，**不单调**。
- **要测什么**：需要一套带标签的失败样本（A–G 各 ≥20 条），才能把 `◐` 从设计判断变成测量。
- **现状**：M2 只到「部分（定义）」；矩阵是分类，不是测量。
