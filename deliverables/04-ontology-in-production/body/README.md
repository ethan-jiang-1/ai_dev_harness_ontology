# 04 主体：建、用、治

> 三册不是三本书，是一条链的三段；每册都按「问题 / 做法 / 接口 / 验收 / 不能证明」写。

| 册 | 回答 | 读者 | 先读 |
|---|---|---|---|
| [build.md](./build.md) | 本体怎么建到“可消费” | 本体/数据工程师 | CQ + 负例 |
| [consume.md](./consume.md) | KG 怎么构建、问题怎么查、语义层怎么接 | 应用/agent 工程师 | schema grounding |
| [govern.md](./govern.md) | 权限/来源/时效/审计/输出校验怎么进接口 | 治理/安全/合规 | 权限 + 审计 |

**顺序**：build → consume → govern；但治理会打回前两段。先读你卡住的那一段，再回 [地图](../sections/map.md) 看交接。
