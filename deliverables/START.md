# 从这里开始：本体接进 harness，到底能指望什么

> **给谁**：第一次来、对本体或 agent harness 不熟的人。
> **读完你能**：说出这份档案的三条主判断、四份交付物各回答什么、哪些话现在还不能信。
> **不要求**：先读 `topics/`、先懂 SHACL/OBDA/τ²-bench，或先认同任何结论。

## 1. 先看一个落差

两个团队都在做「给 agent 挂本体」。

**A 团队**把结构化工件塞进上下文——摘要树、大纲、wiki、实体图。在强检索 harness 下，这些工件在 FRAMES 上没有可检出的准确率增益；同规模的大纲反而退化（E-01）。但要注意：**那篇论文里的 ontology 是 `not measured`**。所以它既不能证明「本体有用」，也不能证明「本体无用」。

**B 团队**没建塔，先把表名、列名、单位、槽位对齐（这一步叫 K1）。在单工厂、9 个任务、答案基本写在文本里的设置下：K0→K1 的避坑率提升是 **+54.6pp**；在此基础上再把领域知识投影成文本（K1→K2），避坑率 0.605→0.802，**再加 +19.8pp**（E-12）。

这两件事**不是同一实验里的 A/B 对照**，不能相减。放在一起只说明一件事：**先问「本体被放在回路的哪一格、以什么形态被执行」，比先问「本体质量高不高」更有用。**（后半句是研究纲领的判断，`推测`；见 [THESIS](../THESIS.md)。）

## 2. 三个词，先说清

| 词 | 人话 | 不是什么 |
|---|---|---|
| **本体** | 领域概念、关系与约束的显式规范，独立于某一次模型调用 | 不是知识图谱（那是实例层），不是词表/分类法 |
| **harness** | 包住模型的那圈工程：上下文怎么拼、状态怎么存、动作放不放行、结果怎么验、过程怎么记 | 不是「Agent 框架」的同义词，也不是模型本身 |
| **接缝** | 本体与 harness 真正耦合的位置，语义在这里变成控制 | 不是「集成点」或「接口层」 |

本档案把接缝分成六格：`context`（模型看到什么）、`memory`（下一轮记得什么）、`evidence`（产出带什么依据）、`checker`（产出对不对）、`action`（动作能不能做）、`commit`（够不够授权落盘）。六格问的问题不同，**不是六个都该做**。

## 3. 三条主判断

1. **本体最确定的角色，是「可求值的约束/查询对象」，不是「更懂业务的提示词」。** 四个开源项目在 pin commit 上给出四种执行语义：OWL 2 QL 查询重写、SHACL-AF 策略求值、SHACL 校验、SHACL→SPARQL。**「有引擎」不等于「会拦」，更不等于「有授权」**（E-20）。
2. **今天能拿到的最大知识增益，来自薄语义层，不是深度结构。** 命名+单位（K1）+54.6pp，整座塔投影（K2）只再加 +19.8pp；而且只在单工厂、9 任务、答案基本写在文本里的条件下测过（E-12）。
3. **约束类机制能改变走向，但收益不普遍、随模型能力下降，误拦还没有测。** 18 个模型-域组合里只有 8 个整体改善；retail 和更强模型常回退；T1-only 接近 blanket veto；false-veto 未测（E-04/E-13）。

如果只记一句：**本体 + harness 今天能做的，不是「让模型更准」，而是「在少数接缝上让某些事不发生」；而且要先证明它没有把对的事拦掉。**

## 5. 哪些话现在不能信

- **最高等级是「已核」，不是「已证」**：本仓库没有独立复现；「能落地」只表示「有实现/公式 + 一手证据 + 边界能写进验收」。
- **不能说「本体无增益」**：E-01 的 ontology 是 `not measured`，它测的是摘要树/大纲/wiki/实体图。
- **不能把 E-12 外推**：单工厂、9 任务、答案基本写在文本里；换域要重测。
- **不能把 E-04 当「护栏总是更好」**：18 格仅 8 格改善；false-veto 未测；reward 不是 harm 度量。
- **04 的 fixture 是合成的**：数字是期望值，不是实测；`conditional` 不是失败，是未决项。
- **多智能体共享本体、本体自动生成**：只有方向或派内机制，没有形成 E；标 `undetermined` / 非本表范围。

## 6. 三条「不要先做」

1. **不要先建整座本体塔**：先 K1（名字/单位/槽位），再决定要不要投影或编译。
2. **不要同时上三个接缝**：选一个做 shadow，先量 1–3 个数。
3. **不要把「有引擎」当「会拦」**：先问机器到底执行了什么语义，再问它有没有权改变世界。
