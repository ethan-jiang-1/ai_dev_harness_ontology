# 交付物质量评分卡（v1）

> **这一页是评估 `deliverables/` 的唯一口径。** 以后评 01–04，先读本页，按同一套维度、同一套权重、同一套抽样方法打分；不要临时另起一套。
>
> 它回答的不是「文档全不全」，而是四个问题：**有没有干货、人能不能读进去、结构对不对、说得可不可信。**
>
> 与 [checklist](./checklist.md) 的分工：checklist 管「交稿前别犯错」（链接、枚举、ID）；本页管「成品有多好」，可打分、可比较、可看趋势。

## 0. 三条使用规则

1. **先过门槛，再打分。** 五条硬门槛（§2）任何一条不过，分数不参与排序，直接判「不可对外」。
2. **十二维同权同义。** 维度名、权重、抽样量固定；换维度必须升 major 版本并重跑四份（§6）。
3. **分维报告，不拉平。** 只报总分是没用的：一份可以「专业 90、叙事 40」。结论必须给出**四份的排序 + 每份的短板维 + 三件该改的事**。

## 1. 四个问题 → 十二维

| 你关心 | 簇 | 维度 | 权重 | 一句话 |
|---|---|---|---|---|
| **有没有干货** | A 内容 (30) | A1 事实密度与参照物 | 11 | 能带走几个可核对的具体东西？有没有一个贯穿全篇的固定对象？ |
| | | A2 可执行性 | 10 | 照着能不能做出来？步骤/接口/判据/stop/模板齐不齐？ |
| | | A3 判断增量 | 9 | 有没有一句「不知道就会做错」的非显然判断？ |
| **叙事对不对** | B 叙事 (25) | B1 入门坡道 | 9 | 不熟这套概念的人，5 分钟能不能知道「这是什么、与我何干、读哪」？ |
| | | B2 主线 | 8 | 一句话能不能说出主线？章节是推进还是并列索引？ |
| | | B3 术语负担 | 8 | 首次出现有没有人话解释？内码有没有跑到正文当主语？ |
| **结构对不对** | C 结构 (20) | C1 骨架与寻路 | 7 | 三次点击内能不能找到「我这种情况读哪」？有没有死胡同？ |
| | | C2 冗余与体量 | 7 | 重复多少？脚手架有没有压过正文？主路径多长？ |
| | | C3 一致性与单一真相 | 6 | 同一个数/词/判定，跨页是不是同值同义？ |
| **专不专业** | D 严谨 (25) | D1 证据纪律 | 10 | 每条主张带等级吗？限定在压缩中丢了吗？ |
| | | D2 引文保真 | 8 | 数字和归属回查得到吗？有没有口径混用？ |

> **不设「完整度」维度。** 仓库明确不为「看起来完整」建空节；完整性只在 A2（任务闭合）和 C1（能找到该找的）里量。奖励篇幅会把索引写成注水肉。
>
> **不设「原创性」维度。** 这是研究档案，交付物的任务是消化与重组；有没有新判断由 A3 量，不按「是否首次提出」量。

## 2. 五条硬门槛（一票否决）

| 门槛 | 判据 | 怎么查 |
|---|---|---|
| **G1 数字有主** | 主路径每个数带对象/条件，或紧邻 `E-xx`；附录/数据表可放宽 | 抽 10 个正文数（表外），见 §4 P2 |
| **G2 证据不越级** | 不把 `已核` 写成 `已证`；不把作者主张写成观测；`推测` 不冒充事实。单句误标按 `D2` 计并进红旗；同一份 ≥3 处、或误标落在承重结论上，判不过 | 抽 10 条判定句，回查 E 行/digest |
| **G3 主路径自包含** | 读者不打开 `topics/` 能完成本份承诺的任务（[ADR 0010](../adr/0010-three-layer-information-flow.md)） | 冷读代理，见 §4 P3 |
| **G4 链接可用** | 主路径 0 坏链、0 坏锚点；外链存在 | `check_repo.py`（文件链 + 锚点）+ 交付物内链抽查 |
| **G5 无占位正文** | 主路径没有 `TODO` / `待补` / `占位`；已声明的 gap 不算 | grep + 人读 |

> G4 由脚本兜底（文件链 + 锚点）；G1–G3、G5 必须人/agent 抽样。门槛不过时，**不要用总分掩盖**——报告第一节就写「哪条没过、在哪一行」。

## 3. 十二维：定义、锚点、测法

打分用 0–5 整数，只定义 0 / 2 / 4 三档，1 / 3 / 5 取相邻档之间。**2 是及格线，4 是「可以拿去给外部评审」，5 是「本仓范本」。**

### A1 事实密度与参照物（11）

- **问**：读完能带走几个可核对的具体值（数、阈值、接口、代码锚、成本、失败模式）？有没有一组数/一个例子被多页引用，成为共同参照物？
- **测**：正文每千字具体值数；抽 10 个值判「有主」；数「被 ≥3 页引用」的对象。
- **0**：全是框架名和形容词。**2**：有数字但散落，各页各说各的。**4**：每节都有可核对的值，且有一组数被多页引用。**5**：4 + 一个可复算的完整参照物（fixture / 填好的产物包 / 账本样例）。

### A2 可执行性（10）

- **问**：读者能不能照着做出产物？有没有步骤、输入输出、判据、未通过怎么办、什么时候停？
- **0**：只有原则。**2**：有步骤，但没有输入输出和验收。**4**：每步有输入/输出/核对点，每项有 pass 与 fail 处置。**5**：4 + 一份填好的样例 + 换域的第二例。

### A3 判断增量（9）

- **问**：有没有一句「如果不知道这个就会做错」的判断？它非显然、有条件、可证伪吗？
- **0**：文献复述或框架搬运。**2**：有观点，但不可证伪或放之四海皆准。**4**：有明确、非显然、带条件的判断（例：「强端不是更好，是更窄」）。**5**：4 + 它改变了默认做法，且有 before/after 对照。

### B1 入门坡道（9）

- **问**：一个聪明但不熟本体/harness 的人，5 分钟内能不能知道「这是什么、为什么与我有关、我该读哪」？第一屏有没有具体场景先于术语？
- **测**：冷读 5 分钟，记「第一句有用的话」在第几屏、遇到几个未解释术语、要不要先读别的。
- **0**：开门就是内码与矩阵。**2**：有读者卡和结论，但没有场景。**4**：开头有一个具体任务或失败场景，术语延后解释，读者能自我归类。**5**：4 + 有一条贯穿全文的「读者问题 → 答案」主线。

### B2 主线（8）

- **问**：一句话能不能说出这份的主线？章节是在回答上一章留下的问题，还是可以任意换序？
- **0**：链接集合。**2**：有目录逻辑，但章节平铺。**4**：每章承接上一章的问题，结尾收束到可执行结论。**5**：4 + 有一条叙事张力（常见做法错在哪 → 证据 → 改法）。

### B3 术语负担（8）

- **问**：术语首次出现有没有人话解释？内码（`E-xx`/`P1a`/`D1`/`M1`/`R6`）是不是只在出处层出现？句子能不能一遍读懂？
- **测**：抽 10 个高频术语看首现处 ±1 段有无定义；统计正文（去表格/链接）内码密度；句长中位数与 p90；英文缩写有无中文对照。
- **0**：内码当主语，读者必须先去 `topics/` 解码。**2**：有术语表，但正文首现不解释。**4**：首现即解释，内码只在括号/出处；长句有断句。**5**：4 + 用类比或例子解释抽象概念，且没有牺牲准确。

### C1 骨架与寻路（7）

- **问**：结构是否按读者任务而不是按文件组织？能不能在三次点击内找到「我属于哪种情况、读哪」？有没有孤儿页、死胡同、只有索引没有内容的页？
- **0**：目录按文件名排。**2**：有索引，但按文档结构而非问题。**4**：任务索引 + 每页有「上一页/下一页/卡住去哪」。**5**：4 + 症状地图/决策树，能处理「我不知道自己属于哪种情况」；图承担解释而非装饰。

### C2 冗余与体量（7）

- **问**：四份之间、章节之间重复多少？索引/关系/模板这类脚手架有没有压过正文？主路径多长？
- **测**：跨文件 6-gram 相似度；脚手架字节占比；主路径（必读页）字数；README 是否只做索引。
- **0**：大段复制，改一处要改四处。**2**：重复但一致，靠人维护。**4**：同一事实只有一处 canonical，其余引用；主路径 ≤ 2 万字。**5**：4 + 四份各有不可替代的形状，不为对称而写小节。

### C3 一致性与单一真相（6）

- **问**：同一个数、同一个词、同一个判定，在不同页是否同值同义？两个读者按规则会不会得出同一结论？
- **测**：5 个高频数跨页比对；3 个边界案例试判；术语表与正文对账；`updated` 与上游 E 的状态是否同步。
- **0**：互相冲突。**2**：大体一致，偶有漂移。**4**：canonical 表 + 交叉引用，边界案例有唯一判定。**5**：4 + 判定顺序显式、`undetermined` 被保留而不是被填成 pass。

### D1 证据纪律（10）

- **问**：每条主张是否带等级？限定条件在压缩中丢了吗？有没有区分「论文发现 / 仓库推断 / 工程建议」？
- **0**：无等级。**2**：页级一句「最高已核」，逐条不标。**4**：逐条/逐数带等级与限定；三源分开。**5**：4 + 明确写出「这条是作者主张，不是观测」这类边界。

### D2 引文保真（8）

- **问**：数字与归属能否回查上游？有没有张冠李戴、口径混用（如把 precision 与 catch 拼成一个准确率）、单位/样本量错？
- **测**：抽 12 条带数陈述回查 `topics/conclusions.md` 与 digest；记一致/等价/不一致/无支撑。
- **0**：编造或无法回查。**2**：多数可回查，但有 1–2 处口径混用。**4**：抽查 ≥90% 一致，口径差异有标注。**5**：4 + 主动标出「不可比」并解释为什么。

### D3 边界与可证伪（7）

- **问**：失败模式、反例、「什么会改变结论」是否具体到可指认？stop 规则可执行吗？
- **0**：只有「仅供参考」。**2**：有清单，但泛泛。**4**：每条边界指得到证据/条件，有 stop。**5**：4 + 给出会推翻自己的观测，并说明怎么观测。

## 4. 测量协议（每次照做，别即兴）

| 步 | 做什么 | 量 |
|---|---|---|
| **P0 门槛** | 跑 `check_repo`；grep 占位符；看主路径是否要求打开 `topics/` | G1–G5 |
| **P1 机械** | 链接/锚点、内码密度、句长、脚手架占比、跨文件相似度、主路径字数 | C1/C2/B3 |
| **P2 抽样** | 每份抽 10 个正文数、10 个术语首现、5 个跨页高频数、3 个边界案例、12 条带数陈述 | A1/B3/C3/D2 |
| **P3 冷读** | 给一个不熟本领域的 agent 只读该份 + 一个任务，15 分钟；记卡点、开 `topics/` 次数、第一句有用的话 | B1/G3 |
| **P4 打分** | 按 §3 打分，写证据（`file:line`），算簇分与总分 | 全部 |

**抽样规则**：固定随机种子或「每份取前 10 个不重复样本」，同一轮四份用同一规则；不挑好样本。冷读代理不等于真人，报告里要写明「代理」。

## 5. 折算与分档

**簇分** = 簇内 `权重 × 得分 / 5` 之和；**总分** = 四簇之和（满分 100）。

| 总分 | 判读 | 对应动作 |
|---|---|---|
| **85–100** | 可对外 | 可提案 `deliverable_status: stable`，仍需过门槛 |
| **70–84** | 可读可用 | 保持 `draft`，定点补短板维 |
| **55–69** | 骨架成立 | 正文或入口有明显缺口；**按最低的那一维补，不按总分补** |
| **< 55** | 提纲或索引 | 不是成品；回到「这份回答谁的什么问题」重写 |

> **同分排序**：`D2` 高者优先（可信度 > 可读性）；`D2` 相同则 `D1` 高者优先，再同则 `A2`。研究档案宁可难读，不可失真。
>
> **红旗**：任何一份的 `D2 ≤ 2`，报告第一节必须单列红旗（文件:行 + 错在哪 + 正确值），不能只写在分维证据里。

> 分数不自动改 `status`。**门槛不过时，总分再高也不升**；反过来，低分但门槛全过的文档可以继续作为内部底稿使用。

## 6. 报告格式与版本

- **落点**：`deliverables/_plans/YYYY-MM-DD-quality-review.md`（工作底稿，不是交付物）。
- **固定结构**：① 一页结论（排序 + 每份一句判词）→ ② 门槛表 → ③ 12 维 × 4 份评分表（每格带 `file:line` 证据）→ ④ 与上次的 delta → ⑤ 只做三件事。
- **delta**：同一维度与上次比 ±1 才值得写；改了什么、为什么，写一句。
- **版本**：本页 `version`。**改维度集合/权重/门槛 = major，必须重跑四份并写迁移说明**；改锚点措辞 = minor；只加例子 = patch。
- **v1.1（2026-11-11）**：G2 的「单句误标」从「直接判不过」改为「计 D2 + 红旗，≥3 处或落在承重结论才判不过」；新增同分排序与红旗规则。**维度、权重、抽样量未动**，v1.0 的基线分数仍可比。
- **历史**：2026-11-10 的 D1–D10 评分卡（[gap assessment](../deliverables/_plans/2026-11-10-gap-assessment.md)）是 v1 的前身，只覆盖 01/02/03 且无权重；**不再作为评估口径**，只作当时证据。对应关系：D1→A1、D2→A1+D1、D3→B2、D4→A2、D5→B3、D6→C3、D7→A2、D8→D3、D9→C3、D10→A2+B1。
