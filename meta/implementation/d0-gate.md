# D0 asset gate（2 天，开跑前）

> 三个试点协议是 v0 draft；**D0 不过，不开跑**。  
> 目的：用 2 天确认“域/数据/人/单价/评审”是否存在，避免把 2 周试点做成“边建资产边跑”。

## 0. 规则

- D0 只做“有没有、谁负责、在哪”，不做实验。
- 任一项 `no`：对应试点降级为“只建资产”，不跑 trials。
- 5 项全 `yes`：按 playbook 第 1–2 周开 EXP-004。
- 所有 `yes` 都要有**具名 owner + 路径/链接 + 日期**；口头不算。

## 1. 五个 gate（总表）

| Gate | 问题 | N&D | action-gate | checker | 签核 |
|---|---|---|---|---|---|
| G1 域 | 具体域/设备/工具集/KG 是否具名？ |  |  |  |  |

| G5 评审 | 盲评 2 人 + 仲裁 + 签核人？ |  |  |  |  |

## 2. 分试点 checklist

### EXP-004 N&D

- [ ] 1 台设备，名称/版本/负责人。
- [ ] 3 个任务卡（ground truth + primary trap + rubric）。
- [ ] 1 curator（建 162 节点 1/10 塔）+ 1 后端（45k 投影/日志）+ 1 领域工程师（任务/评分）。
- [ ] K1 命名/单位审计清单（tag/单位/binding）。
- [ ] 2 名盲评 + 1 仲裁；judge 版本/温度/prompt 冻结。
- [ ] 单价：人日价（至少内部估算）；排障工时基线。

### EXP-005 action-gate

- [ ] 1 个具名域 + 工具集 + mutating tools 清单。
- [ ] ≥500 条历史决策，每条带 `state_hash`（或可重建状态）；没有 → 先补 logging。
- [ ] Layer A 本体 v0 owner + `w` rubric；legal codebook v1。
- [ ] 100 条 blocked 的过采样方案（500 条不够就扩 N；95% 保留率需 ~2,000）。
- [ ] 2 名盲评 + 1 仲裁；访问审批/日志权限。
- [ ] 单价：审批分钟价/人时价（可空，但空则 NPV 只能给敏感性）。

### EXP-006 checker

- [ ] 1 个具名 KG + 访问方式 + 数据版本。
- [ ] 200 题题库 + gold + 分层比例（真实错/人工故障/正确）；目标 ≥80 错误。
- [ ] checker 实现 owner；空结果重试基线可跑。
- [ ] 100–200 条正确题复核；2 名盲评 + 仲裁。
- [ ] 单价：token 单价/人时价；空则 per-1k 门只能“不出结论”。

| D2 下午 | G5 评审 + 签核；决定开/不开 | D0 签核页 |

## 4. 决策

- **全 yes**：开 EXP-004；同时准备 EXP-005/006 资产。
- **部分 yes**：只开有资产的；其余只建资产，不跑。
- **全 no**：本阶段停在协议；不写“可开跑”。
