# 写作约定

## 证据等级

四个等级，**升不上去就不许写**：

| 等级 | 含义 | 出处要求 |
|---|---|---|
| **已证** | 本仓库内可复现 | 需实验编号 |
| **已核** | 读过一手原文（至少摘要），引文准确 | 需卡片或原文链接 |
| **推测** | 有线索、未核原文，或来自二手转述 | 标注来源，写清为何未核 |
| **存疑** | 有反例，或证据互相矛盾 | 必须写出反例 |

**默认是推测。** 没标等级的论断，一律按推测看待。

> 不要与「接地等级」混淆：接地等级是 OA-RAG 那套 entailed / supported / related / unrelated，描述输出与本体的关系；证据等级是本仓库对主张的置信度。见 [GLOSSARY](../GLOSSARY.md#证据)。

## 引用

| 情况 | 写法 |
|---|---|
| 一手 | 链接到 `src_raw/` 下的原文件，或 arXiv 编号 |
| 二手转述 | 写「转述自 X」，并加 `待核` |
| 未读原文 | 不许写成事实；写成「某文报告」 |

**综述的一句摘要不是论文结论。** 本仓库已经因此踩过一次坑：三篇论文的转述丢了限定条件，见 [综述卡](../src_notes/cards/2026-11-04-ontology-20-papers.md#转述与原文的差异)。

## 字段与词汇

同一个字段在不同目录不能有不同含义。本仓库用以下字段，各自一套词汇：

| 字段 | 用在哪 | 取值 | 含义 |
|---|---|---|---|
| `status` | 所有文档 | `seed` / `draft` / `stabilized` / `superseded` | 文档成熟度，不代表篇幅 |
| `home` / `subtopic` | `src_notes/` 卡片 | `topics/<派>` / `<子主题>` | 卡片归位；移动子主题只改 `subtopic` |
| `source_type` | `src_notes/` 卡片 | `paper` / `preprint` / `blog` / `engineering` / `standard` / `talk` / `survey` | 素材类型；证据天花板见 [source-types](./source-types.md) |
| `reading` | `src_notes/` 卡片 | `未读` / `综述级` / `摘要级` / `精读` / `已消化` | 读到什么程度 |
| `provenance` | `src_notes/` 卡片 | `原文正文` / `原文摘要` / `综述转述` / `未核` | 证据来自哪里 |
| `experiment_status` | `experiments/` | `未开始` / `设计中` / `运行中` / `已完成` / `已放弃` | 实验阶段 |
| `deliverable_status` | `deliverables/` | `draft` / `stable` / `frozen` | 交付阶段 |

`status` 的判据：

- `seed` — 结构在，内容已开始，但未交叉核对。
- `draft` — 论证完整，至少经过一次交叉核对；结论可能变。
- `stabilized` — 结论稳定，可被交付物引用。
- `superseded` — 已被别的文档取代，保留指针。

`updated` 表示「最后一次实质修订」；搬家、改链接、批量重排不算。不要为了显得新而改日期。

**文档状态与笔记进度是两件事。** 一张 `reading: 摘要级` 的卡，其 `status` 通常是 `draft`；不要写 `status: 摘要级`。

正文里的推断句，至少在段末标一次 `已核` / `推测` / `存疑`；引文来源用 `一手摘要` / `一手正文` / `转述`，并按下面的映射读：

| 正文写法 | 对应等级 |
|---|---|
| 一手正文 / 一手摘要 | 已核 |
| 转述 / 待核 | 推测 |
| 反例 / 冲突 | 存疑 |

## 命名

- 目录：小写短横线；论文卡用 `{arxiv_id}-{slug}.md`
- 子主题目录：`topics/<派>/<子主题>/README.md`；按子机制命名，不按来源类型。派 README 只做地图，详细论证在子主题
- 结论编号：`E-xx`（结论）/ `Q-xx`（存疑）/ `C-xx`（冲突）
- 实验编号：`EXP-xxx`

## 台账纪律

每次动笔后回答三句：

1. 这份材料/这篇文档**改变了哪条判断**？→ 去改 [conclusions](../topics/conclusions.md)
2. **喂给了哪个主题**？→ 去改 [notes 台账](../src_notes/README.md)
3. 如果修正了旧判断，**哪些主题页要回改**？→ 写进卡片的 `updates:`，逐页改。

三句都答不上来，说明这次动笔没有产生信息。
