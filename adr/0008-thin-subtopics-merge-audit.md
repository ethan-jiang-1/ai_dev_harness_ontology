# ADR 0008：薄子主题合并审计——本轮不合并

- 日期：2026-11-09
- 状态：接受

## 背景

2026-11-09 的评审发现 20 个子主题里有 15 个独立来源 <2（其中 4 个主归位 0 篇），并在派 README 标了「薄页」。用户要求把薄子主题合并掉。合并前做了一次逐页审计：看它是不是**独立机制**、有没有**独立判断**、需不需要**独立 frontier**。

## 审计

来源数按 `subtopic` + `also_supports` 统计；F/G 是该页 `findings.md` / `frontier.md` 的编号条数。

## 决策

1. **本轮 0 个合并。** 15 个薄页都有独立机制或独立判断；合并会把不同时刻/不同证据线压成一个房间，违背 ADR 0003「子主题按子机制」。
2. **「薄」是来源计数，不是冗余信号。** 薄页可以保留，但不承担稳定判断；派 README 的「薄页」标记继续保留。
3. **合并门槛**（以后用）：同时满足（a）是父机制的属性、没有独立判断；（b）F <2 且无独立 frontier；（c）合并不改变 `seams`/派轴的含义。当前没有页面同时满足。
4. **下轮复核**：`determinism`（0F/0G）与 `lifecycle`（0F/0G）如果下一轮仍无 F，优先考虑并入相邻页；其余薄页按 frontier 继续长。
5. **新子主题门槛**：仍按 ADR 0003 的 ≥2 来源；例外要写明「为什么不能塞回父页」，并在派 README 标薄页。

## 后果

- `meta/state` 的薄页计数从 16 修正为 **15**（此前多算了一个）。
- 不移动目录、不改 `subtopic`/`also_supports`；链接与 checker 不受影响。
- 合并问题从「未做」变成「已审计、有规则、有下轮复核点」。

## 考虑过的选项

- **全部合并**：会删掉 calibration 的阈值/代价、identity 的跨期同一性、feasibility 的落地经济学等独立判断；否决。
- **只合并 0 来源页**：determinism 是第六时刻、feasibility 是 RQ5 的家；合并会破坏轴；否决。
- **保留 + 规则 + 下轮复核**（采用）：不破坏结构，同时给出退出条件。
