# OntoDoc

## 做了什么

给任意 IRI 生成自然语言说明，四阶段多 agent：

1. **Database Context**：用 SPARQL 自适应探图，收集有信息量的三元组。
2. **Web Context**：检索并重排百科类背景知识。
3. **Assumption**：生成结构化假设，显式化推断前提。
4. **成文**：写出说明。

针对的问题：规则/模板式 verbalization 太硬，只能覆盖严格公理，传达不了上下文语义。

## 结果

- 151 个术语，覆盖生物医学、农业、开放域；完整性较朴素基线平均 +12%。
- 假设生成阶段在专业域稳定提升质量。
- 11 人人工评估（领域专家 + 学生）与自动评分趋势一致。

## 没测什么

**作者自述**：未在摘要列出。
**读者补充**：只测「说明写得好不好」，未测「有说明之后下游任务是否变好」。

**值得记的**：第 3 阶段「结构化假设」是关键设计——先承认推断用到了哪些前提，再写正文。这与「接地等级显式化」是同一种工程直觉：**把不可见的推断前提摆到台面上**。
