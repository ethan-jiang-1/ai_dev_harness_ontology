# 多 agent 差分诊断

## 做了什么

把临床自由文本转成结构化症状 → 生成候选疾病排序 → 若不确定则**主动生成追问**（单选，yes/no/unsure）→ 用回答更新排序，逐步收敛。

推理**锚定在专家整理的结构化知识库**上，拆成可审计步骤。

## 结果

- 交互式追问的贡献「真实但有限」：Top-1 在两个完整度水平上都提升；**Top-3 只在 80% 完整度提升（25.3%→30.3%），50% 时反而略降（26.3%→24.2%）**。
- 案例显示机制的价值形态：当六个候选同分时，一次针对性确认把相似度从 0.340 拉到 1.0。
- 若已有明确主导诊断，或没有足够接近的候选，追问的贡献按构造即为零。

## 没测什么

**作者自述**：把推理限制在 curated KG 上，**结构性地**防止了「看似合理却无依据」的诊断，但**这个取舍以封顶基准表现为代价**；交互限于 yes/no/unsure，丢失严重度与时间进展。

**读者补充**：无多轮长程评估。
