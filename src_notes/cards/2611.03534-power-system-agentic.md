# Grid Agents

## 做了什么

把并网评估的两项稀缺技能合到一个系统里：按不断变化的法规核查申请，跑决定接入方式的电网研究。

三条原则写得极干净：

1. **答案必须引用证据。**
2. **每个数字都由成熟求解器算出**，模型不生产数字。
3. **人做最终决策。**

Grid Ontology 是它的知识系统：承载法规、标准与工程知识，可检索，并随使用演化。

## 结果

- Grid Ontology 在法规证据检索上优于通用编码 agent 与检索管线；LegalBench-RAG 领先；Enterprise RAG Challenge 与 ViDoRe V3 公开榜第一。
- 8 个公开电力系统基准族、519 个任务上，Grid Studio 得分最高且 agent 工作时间最短。
- 求解器在环时，加固方案平均便宜 33–67%。

## 对本仓库的意义

| 关联 | 关系 |
|---|---|
| 01/02 派的分界 | 它是「知识 + 判定」的组合：知识负责检索证据，判定要求引用，求解器兜住数字 |
| [domains](../../topics/domains.md) | 电网域的完整形态 |

**可迁移的形态**：把「不该由模型决定的量」整体外包给求解器，模型只负责组织与引用。这比让模型算完再校验更省事，也更硬。
