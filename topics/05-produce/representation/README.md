## 当前判断

- **已核（限 SFE-O，单域、无 agent 评测）**：OWL 2 表达力够，但数值不在 OWL 里求解，约束尚未成为可执行 SHACL shapes，热物性/扩散系数靠外部服务。局限在执行，不在表示。`已核`
- **本页假设（`推测`）**：表示档位应按消费位置选；三档之间可能有工程成本差。没有直接文献，SFE-O 没有比较三档；这是本页最薄的一处。
- **可消费性 = 三关记录（`推测`）**：load / validate / answer 各有可测判据；现有 `build_report` 只覆盖前两关的一部分，10 个坏样本里只有 2 个被稳定抓住。三档能力矩阵见 [consumability](./consumability.md)。

## 问题

同一份领域知识可以用 OWL + 推理机表达，也可以用一份 YAML 约束表达。问题是：在什么消费位置上，哪种表示才划算；两者成本差多少，本页没有测量（`推测`）。

## 一条反直觉的立场（`推测`）

**本页假设：表示形式的选择应由消费位置决定，而不是由语义完备性决定。**

| 消费位置（假设） | 本页假设所需能力 | 本页假设的过度形式代价 |
|---|---|---|
| 上下文中注入（弱约束） | 自然语言 + 少量结构 | 形式化不产生约束，只占预算 |
| 判定器（强约束） | 可判定的约束、可查询的关系 | 推理不可控时，判定结果无法解释 |
| 记忆状态（中约束） | 槽位与关系的定义 | 过重的模式让状态更新成本过高 |
| 授权判据（最强） | 可由事实查询直接判定的谓词 | 谓词依赖推理链时，授权时延不可接受 |

这张表是本页综合出的选型假设（无直接文献），不是 SFE-O 的结论；论文没有比较不同消费位置的成本，也没有下游 agent 评测。已核的只有一条：逻辑档（OWL 2）表达力够，但不自动带来可执行性——数值、约束执行、外部服务仍在 OWL 外。

推论：若这张表成立，顺序应是先定接缝位置、再定表示（`推测`）。反过来做，可能得到一个正确但无法消费的本体；这是本页推断，不是测量。

## 形式化的三个档次

| 档次 | 形态 | 本页假设的适用（`推测`） |
|---|---|---|
| 词表决 | 概念与关系的清单 | 协作契约、检索增强 |
| 结构表 | 概念 + 关系 + 基数/类型约束 | 判定器、记忆槽位 |
| 逻辑表 | 类公理、可推理的约束 | 需要推导隐含结论的场景 |

三档的性价比没有测量。SFE-O 只覆盖第三档的「表达 ≠ 执行」：OWL 2 能表达类/关系/约束，但论文明确说约束尚未成为可执行 SHACL shapes，热物性/扩散系数仍是外部服务（`已核`，限该文）。这不能推出第二档够用，也不能推出第三档不划算。

## 失效模式（`推测`，工程经验归纳，未测量）

- **形式化被当作目的。** 建了 OWL 文件但没有消费者，最终退化为文档。
- **两种表示并存且不同步。** 自然语言规范与形式化模型各自演化，模型把矛盾的两份都读进上下文。
- **约束仅可读不可执行。** 写在注释里的业务规则，判定器看不见。
- **把校验报告当判定。** SHACL 只回答「违反/未违反哪条 shape」，不回答「这批数据能不能用于决策」；论文未做判定器评测（[findings/F2](./findings.md)）。

## 开放问题

1. 第二档（结构表 + SHACL）能否覆盖大多数判定场景？边界在哪。本页假设，未测。
2. SHACL shapes 落地后，能否被 agent/判定器直接消费，而不只是产出违规报告？SFE-O digest §9 的开放问题，未测。
3. 数据矛盾如何进入下游判定的置信度？`contradicts[]` 与 `confidence` 的联动没有定义。SFE-O digest §9，未测。
4. 能否用同一份源生成两种表示（人读/机判定），避免双份不同步？
5. 参数的**来源**是否应作为一种关系进入本体？SFE-O 已把参数溯源建进本体，但没有测它是否改变下游判定。
