# 尺子一：本体知识真的在模型里吗

## 问题

大量工作默认「模型能答对本体题 ⇒ 它掌握了本体」。这个推断跳过了中间一步：**答对可能来自表面模式，而不是内部结构。**

MIOE 用因果抽象基准来测这一步：对实体类型与上义关系两个任务做 interchange intervention，检验内部干预能否改变本体层答案，同时保留类别级辅助信息。

## 结果（一手正文，`已核`）

- 本体层预测**机制上可干预**——说明存在可定位的内部表征。
- 但**无法与类别辅助信息干净分离**：最好的 MDAS 在 instance of 上 Disentangle 只有 0.592/0.587（Entity/Context），subclass of 0.513/0.542；没有方法到达 Cause=1、Iso=1。
- **Distributed subspace 方法 > SAE/DBM**：SAE 在 instance of 上只有 0.412/0.371；DAS 0.584/0.547；MDAS 最强。
- **多任务是 Iso/Cause 权衡**：Iso +0.081、Cause −0.052；Disentangle 提升，但不是免费。
- **中后层连续窗口 > 单层**：四层 DAS 512×4 达 0.667（+0.102），说明相关计算分布在短层段而非单点。
- **分离程度按类别而异**：具体/规则类（airport/country/currency/university）较好；宽泛/异质类（body of water/geographical feature/food）较差；聚合分数掩盖这种差异。

作者的原话给了最克制的解读：对 LLM 在本体工程上的表现应作**有保留的解释**——正确的本体预测本身，并不意味着干净的内在本体。

## 为什么这条对本仓库重要

它否掉了一种常见的论证捷径：用「模型答对了本体题」当作「本体已经内化」的证据，进而推出「不需要外部约束」。

如果内在本体既存在又不可靠、还无法与无关信息分离，那么**外部判据（02 判定派）的必要性反而增强了**——你无法信任一个你测不出边界的内部结构。

## 它的边界

- 只测了两个模型（Qwen3-8B/4B）与两类任务（实体类型、上义）。
- 机制可干预 ≠ 干预方向可控；这里的结论是「可以被影响」，不是「可以被精确控制」。
- 「部分分离」可能是表示本身纠缠，也可能是干预方法不够强；本文不能区分。
- 未回答：更大的模型/其他模型族是否分离得更好；更丰富的本体约束（disjointness/domain-range）是否同样。

## 开放问题

- 跨模型族（Llama/GPT）是否同样部分分离？
- 更丰富的本体约束能否用同样方法测？
- 干预位置（subject token 之外）是否改变结论？
- 类级差异能否预测下游本体工程任务的表现？
- 能否用机制指标筛选「可信的本体判断」？
