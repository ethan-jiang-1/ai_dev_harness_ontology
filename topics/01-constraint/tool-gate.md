# 时刻 1 · 动作执行前

## 位置

模型决定调用某个工具、且尚未真正调用之前。这是唯一能**阻止**副作用的位置——再往后只能事后补救。

## 机制：可逆性分级

不是给动作打「危险/安全」标签，而是打**可逆性分值**：

| 判据（由本体提供） | 取值 |
|---|---|
| 该对象是否有备份 | 是 / 否 |
| 是否有下游消费者 | 是 / 否 |
| 变更是否可被精确撤销 | 可逆 / 有损 / 不可逆 |
| 影响范围是否已知 | 已知 / 未知 |

低于阈值即剪掉，不进入执行。关键在于**判据是可查询的事实**，而非对动作的主观评价：

> 「删除 `/tmp/x.log`」是否危险，取决于它是不是唯一副本，而不是「删除」这个动词。

## 证据：一个被转述掩盖了的权衡

POLAR 用两层本体推导候选逆操作序列，给动作打可逆性分，低于阈值在执行前剪枝。τ²-bench 六个模型的结果是：

- airline 域：四个模型的平均任务奖励提升 0.11–0.18。
- **但 18 个模型-域组合里只有 8 个整体改善；retail 与更强的模型经常回退。**

作者还明确声明「reward 不是防止伤害的直接度量」——被剪掉的风险动作不会体现在奖励里。

（一手摘要，[POLAR](../../notes/papers/2610.08082-polar.md) → [E-04](../conclusions.md)）

**这个结果比「护栏有效」更有用**：它给出了一条可检验的规律——**护栏的收益与模型能力反向**。强模型本可以自己避开那些错误，此时硬护栏只剩下代价。

## 这个位置为什么硬

- **在副作用之前。** 判定发生在世界被改变之前，失败成本最低。
- **判据可外部验证。** 「有没有备份」是可查的事实，不依赖模型自评。
- **拒绝可解释。** 剪枝理由可以直接回给模型，让它换策略而不是重试。

## 失效模式

- **判据依赖运行时状态。** 可逆性随环境变化（是否有其他进程在读），静态本体不够，需要状态输入——又把 [memory-as-state](../04-state/memory-as-state.md) 拉回回路。
- **阈值错置。** 阈值太高，正常操作被频繁剪枝，模型学会绕行；阈值太低，等于没有。
- **只判不记。** 剪枝事件不被记录，事后无法知道「本可以做的事为何没做」。
- **粒度按工具而非参数。** 同一删除工具，删临时文件与删生产数据共享一个权限位。

## 开放问题

- 可逆性能否作为工具契约的一等字段，由工具提供者声明而非判定器推测？
- 剪枝与澄清的界限在哪：不确定时应当阻断、追问，还是放行并记录？
- 多步动作的复合可逆性如何计算？单步都可逆，组合可能不可逆。
