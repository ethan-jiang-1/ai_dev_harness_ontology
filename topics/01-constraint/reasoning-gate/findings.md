## F1 · 独立位置

- **判断**：比动作闸门更早，比输出判定更深；判据来自本体，不是模型自评。
- **证据**：OntoAct 在三环境提升成功率、降无效干预；多 agent 诊断在小样本上 Top-1 +2.5 pp。
- **边界**：两篇都是模拟/小样本；没有真实工厂/临床。
- **来源**：OntoAct §5；多 agent §IV。

## F2 · 形式决定天花板

- **判断**：验证条件（OntoAct）通常不封顶；限制知识源（curated KG）可能封顶。
- **数字**：OntoAct Tacit-FLE 78.6/83.3/90.0 vs IfR 64.3/66.7/65.0；多 agent Top-1 18.7→21.2，但 Jaundice/Vertigo 恒 0。
- **边界**：不同任务形态；不能直接说「验证条件一定更好」。
- **来源**：OntoAct Table 1；多 agent §IV-C。

## F3 · 三值条件

- **判断**：⊤/⊥/?；? 触发观察/追问，不直接 block；避免把「不知道」变成「不允许」。
- **证据**：OntoAct 的 condition report + hypothesis revision。
- **边界**：schema 固定；真实传感器噪声未测。
- **来源**：OntoAct §4。

## F4 · 覆盖率

- **判断**：没有适用 axiom 的动作/假设只能放行/fallback；覆盖率决定它是不是「选择性护栏」。
- **等级**：`推测`（作者未给覆盖率）。
- **边界**：需要统计每域 axiom 覆盖率。
- **来源**：OntoAct §4–5；digest §5。
