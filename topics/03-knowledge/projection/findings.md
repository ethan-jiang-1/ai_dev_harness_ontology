## F1 · 文本投影 pooled 分最高（不是普适排序）

- **数字**：pooled element score 文本 0.777；打乱 0.685；JSON 0.717；查询工具 0.638；文档检索 0.597。
- **条件**：N&D 单 plant、9 tasks、4 模型；1,304 trials 覆盖 K0–K4 等九个预注册条件；**JSON 与工具的比较是事后描述性、不是受控实验（K2-tool 明确不在 1,304 预注册批次内）**。
- **评分可靠性**：两个 LLM judge 在 primary-trap 上 κ=0.819（121 个抽样 trial）；作者与 judge κ=0.696（仅 7 个 trial，低于预注册 0.7）；element score 的评分者一致性未报。0.777 / 0.717 等分只在这套 rubric 与 judge 下成立。
- **反转**：GLM-5.2 的 JSON 0.900 > 其文本 0.891；Qwen 的查询工具 0.407 < 其文档检索 0.538。**用法差异**：EXAONE 只调了 2/27 次工具。
- **结论**：只支持「默认固定分节文本 + 按模型/任务复测 JSON/工具」，不能写成「投影 > JSON/查询/检索」的普适结论。
- **边界**：任务答案基本写在投影里；物理推导未测。
- **来源**：Table 2, p.16；§3.2、§4.2、§4.4。

## F2 · 已测得的最大一层是命名+单位

- **数字**：K0→K1 避坑率 +54.6 pp；K1→K2 +19.8 pp（95% CI +3.0~+38.4）；element score 0.566→0.777；H2 p=0.85（增益不随容量上升）；9B 带投影 0.737 > 750B 不带 0.672（区间约 0.3 宽，不能当普遍规律）。
- **含义**：在已测的累积条件（K0→K1→K2）里，命名+单位是最大的一步。预算顺序应先修 tag 名/单位，再谈建塔与投影。
- **物理深度未测**：16 个推导量与假设在塔里、不在投影里（§3.2），9 个任务也没有一个要求推导量（§5.2）。所以「物理深度不是最大一层」没有对照，不能由 +54.6 pp 推出（§5.1）；要比较，得把推导量写进投影并设计必须用推导量的任务（§9，记 [frontier](./frontier.md) G5）。
- **边界**：单 plant；9 任务；四个模型。
- **来源**：§3.1, p.13–15；§4.1、§4.4、§5.1–5.2、§9；Fig. 3/4。

## F3 · 运行教训在抽取时并入才常用

- **数字**：日志检索在 K4 诊断 trial 中只被调用 4/80 次，两个模型从未调用；移除已并入的教训 element score −0.20（SE 0.05）。
- **H3 未支持**：预注册 H3 是「本事故记录提高诊断分」；K4 0.644 vs K4x 0.645（element score，4 个诊断任务，差 <0.01）。K4x 是 H3 的操纵条件，不是探索性比较（§5.6）。K4 是累积条件（含 K2 投影），两臂只有「日志里有没有本事故记录」一处差别、投影相同，所以这组只隔离「日志里的本事故记录」，不能回答「检索整个日志有没有用」；零结果与 4/80 的检索率一致——「可检索」不等于「会被用到」。
- **digest 边界**：本页只按 digest 的两条路径（并入塔 / 留在日志）；「把记录放进提示」不在 digest 条目内，不据此下判断。
- **含义**：差别在**谁决定检索**（抽取时系统 vs 查询时 agent）。由此推断「投影=把归纳提前做掉」是 `推测`；digest 的对照只支持「谁决定检索」，没有「agent 不做归纳」的因果检验（§4.4）。
- **来源**：§4.2、§4.4、§5.6、§6.1。

## F4 · 投影不承担安全边界

- **数字**：live runs 12/14 达标（仅描述 GLM-5.2 与 gpt-5.6-sol，且 gpt-5.6-sol 同时是 judge；两次未进带都从高于平衡的腔温起步，论文说不能据此判断 agent 失败、也不说明目标带是否可达）；61 条命令到达安全层，25 条被拒；24–68% 事实主张无证据**仅 GLM-5.2**（gpt-5.6-sol 4–19%）；至少 4/14 报告未发生的变更。
- **条件**：live run **故意不告诉 agent 允许的 setpoint 与限值**，让它从拒绝中学习；论文没有做「prompt 规则 vs 代码规则」对照。
- **含义**：安全层必须独立于 agent，agent 自述不能作为控制依据。**「投影能被忽略」没有直接测量**，是从上述设计推得的 `推测`，不是论文结论。
- **来源**：§3.4、§4.3。
