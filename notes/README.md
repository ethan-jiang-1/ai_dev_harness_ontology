## 阅读进度（`reading`）

| 值 | 含义 |
|---|---|
| `未读` | 只登记了来源，没打开 |
| `综述级` | 只读了综述/二手转述，未对原文 |
| `摘要级` | 读过论文摘要与首页，知道它做了什么、没做什么 |
| `精读` | 读过正文，能复述方法与结果 |
| `已消化` | 已提炼为可引用判断，并写入 `topics/` |

## 来源（`provenance`）

| 值 | 含义 |
|---|---|
| `原文正文` | 读过论文正文 |
| `原文摘要` | 读过论文摘要/首页 |
| `综述转述` | 只来自综述或二手材料 |
| `未核` | 尚未核对来源 |

**文档 `status` 与阅读 `reading` 是两件事。** 卡片本身是文档，`status` 用 `seed / draft / stabilized / superseded`；`reading` 才表示读到哪。定义见 [conventions](../meta/conventions.md#字段与词汇)。

**卡片状态与 `source/` 的下载状态无关。** 下载只代表「拥有」，不动笔记账。

## 卡片分两种

| 类型 | 模板 | 用于 |
|---|---|---|
| 材料卡 | [_template.md](./_template.md) | 文章、书、演讲、规范。关注「作者主张什么」 |
| 论文卡 | [papers/_template.md](./papers/_template.md) | 单篇论文。关注「它测了什么、结果是什么、没测什么」 |

两者最大的差别：论文卡必须有**结果数字**与**未测范围**两栏。综述最容易省略的正是这两样。

## 一条纪律

卡片写完，必须回答三句：

1. **这份材料改变了哪条判断？** 改变了 → 去改 `topics/`，并在 [conclusions](../topics/conclusions.md) 登记；没改变 → 只增来源，不动正文。
2. **它喂给了哪个主题？** → 更新上面的台账。
3. **它修正了旧判断吗？** 修正了 → 在卡片 `updates:` 列出所有要回改的主题页，逐页改。

如果一份材料既不改变判断、也不提供来源，它就不该有卡片——它只是 `source/` 里的一个文件。
